# 관리자 사용법 — 알부남 신목사 홈페이지

관리자 주소: https://newhome-shin.netlify.app/admin/
공개 사이트: https://newhome-shin.netlify.app

## 0. 처음 한 번만 하는 준비 (오너)

관리자 로그인과 자동 발행이 되려면 아래 두 가지를 네티파이·깃허브 화면에서 직접 설정해야 합니다. 비밀번호와 키를 다루는 일이라 Claude가 대신할 수 없습니다.

### 0-1. 네티파이를 깃허브 저장소와 연결 (자동 발행)
1. https://app.netlify.com/projects/newhome-shin 접속
2. **Project configuration → Build & deploy → Continuous deployment → Link repository**
3. GitHub 선택 → 네티파이 깃허브 앱 설치 허용 → 저장소 `soochul331/newhome` 선택
4. Build command `npm run build`, Publish directory `_site`, Branch `main` 확인(저장소의 netlify.toml이 자동으로 채웁니다) → 저장
5. 첫 자동 빌드가 끝나면 사이트가 지금과 똑같이 보여야 합니다.

### 0-2. 깃허브 로그인 연결 (관리자 로그인)
1. https://github.com/settings/developers → **OAuth Apps → New OAuth App**
   - Application name: `newhome admin`
   - Homepage URL: `https://newhome-shin.netlify.app`
   - Authorization callback URL: `https://api.netlify.com/auth/done`
   - Register → **Client ID** 복사, **Generate a new client secret** → 복사(이 화면을 벗어나면 다시 못 봅니다)
2. https://app.netlify.com/projects/newhome-shin → **Project configuration → Access & security → OAuth → Install provider → GitHub**
   - 위 Client ID와 Client secret 붙여 넣기 → Install
3. https://newhome-shin.netlify.app/admin/ 에서 "로그인" → 깃허브 승인 → 편집 화면이 보이면 완료

허용되는 계정은 저장소 `soochul331/newhome`에 쓰기 권한이 있는 깃허브 계정뿐입니다. 다른 사람을 편집자로 두려면 저장소 Settings → Collaborators에서 초대합니다.

## 1. 로그인·화면 구성
- 좌측 **컬렉션**: 사이트 설정(기본 정보·메뉴·홈 화면), 페이지, 글·소식
- 상단 **미디어**: 이미지 올리기
- 상단 **작업 흐름**: 초안 → 검토 중 → 발행 준비 → 발행

## 2. 자주 하는 일

| 하고 싶은 일 | 어디서 | 방법 |
|---|---|---|
| 첫 화면 문장 바꾸기 | 사이트 설정 → 홈 화면 → 히어로 | 제목·부제 수정 → 저장 → 작업 흐름에서 발행 |
| 메뉴 이름·순서 바꾸기 | 사이트 설정 → 메뉴 | 항목을 끌어 순서 변경, "표시" 끄면 숨김 |
| 홈 섹션 숨기기 | 사이트 설정 → 홈 화면 | 섹션 펼쳐 "표시" 끄기 (내용은 남음) |
| 새 페이지 만들기 | 페이지 → ＋ 페이지 | 제목, 주소(`/lecture/` 형식), 메타 설명, 본문 → 저장 → 발행. 메뉴에 넣으려면 "메뉴"에 링크 추가 |
| 블로그 새 글 올리기 | 글·소식 → ＋ 글 | 제목, 날짜, 외부 링크(네이버 글 주소) → 저장 → 발행 |
| 이미지 넣기 | 본문 편집기의 이미지 버튼 또는 미디어 탭 | 올린 뒤 본문에 삽입. 10MB 이하 |
| 발행 | 작업 흐름 | 카드를 "발행 준비"로 옮기고 **발행** 클릭. 1~2분 뒤 공개 사이트 반영 |
| 되돌리기 | https://github.com/soochul331/newhome/commits/main 또는 네티파이 Deploys | 깃허브에서 커밋 되돌리기(Revert) 또는 네티파이에서 이전 배포 "Publish deploy" |

## 3. 발행이 안 될 때
빌드가 "내용 검사 실패"로 멈추면 네티파이 Deploys 로그에 **어느 파일의 어느 문장**이 걸렸는지 한국어로 나옵니다. 걸리는 것들:
- 금지 표현: "지금 바로", "마감 임박", "서두르세요", "혁명적", "완벽한", "국내 최초", "유일한", "뒤처집니다"
- 이름 표기: "신 목사", "신목사님", "알부남 목사" → 항상 "알부남 신목사"
- 느낌표 2개 이상(파일 단위)
- 경고(멈추지 않음): 메타 설명 80~110자 벗어남, 출처·링크 없는 수치

## 4. 바꿀 수 없는 것(일부러 잠금)
색(배경 #F6F7FB · 글자 #141B34 · 강조 #2747D6), 글꼴(Black Han Sans · Noto Sans KR), 버튼·카드 모양. 디자인을 바꾸려면 DESIGN.md를 먼저 고치고 Claude에게 요청합니다.
