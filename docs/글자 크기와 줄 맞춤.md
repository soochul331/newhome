# 글자 크기와 줄 맞춤

관리자 → 사이트 설정 → 홈 화면 → 수정할 섹션 → **글자 크기와 줄 맞춤**을 여세요.

- **제목·질문 크기**: 작게 − / 크게 ＋ / 기본 크기 버튼으로 조절합니다.
- **설명·본문 크기**: 제목과 별도로 70–140% 범위에서 조절합니다. 자연스러운 줄바꿈을 유지합니다.
- **제목·질문 한 줄 자동 맞춤**: 기본 켜짐입니다. Enter로 나눈 각 줄을 유지하면서, 가장 긴 줄이 들어가는 같은 크기를 적용합니다.
- 너무 긴 제목은 최소 크기를 유지하고 추가로 줄바꿈하며, 미리보기에 안내가 나옵니다. 문장 중간에 Enter를 넣으면 원하는 구성을 만들 수 있습니다.
- 카드에는 개별 크기 설정도 있습니다. 카드 자체 설정이 없으면 섹션 설정을 따릅니다.
- 페이지와 글 편집 화면에도 제목과 본문 크기 조절이 있습니다.
- 오른쪽 미리보기의 **PC / 휴대폰 (375px)** 버튼으로 화면 폭을 바꿔 확인하세요. PC 버튼은 현재 미리보기 영역의 폭을 사용합니다.
- 확인 후 저장·게시하면 공개 페이지에 반영됩니다.

버튼의 백분율은 테마 기본 크기에 대한 비율입니다. 자동 맞춤이 켜진 제목은 공간에 맞춰 그보다 작게 표시될 수 있습니다.
