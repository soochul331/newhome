# 관리자 고정 메뉴와 한 번에 게시

- `/admin/`은 왼쪽 메뉴와 오른쪽 Decap 편집기를 함께 표시합니다.
- 메뉴는 `config.yml`에서 빌드 때 생성하므로 컬렉션과 파일 목록이 함께 갱신됩니다.
- 기존 관리자 링크의 해시 경로는 유지됩니다. 좁은 화면에서는 메뉴를 위에 표시하며 접을 수 있습니다.
- 파일 간 전환은 Decap 목록을 거쳐 편집기를 다시 열어 이전 항목의 데이터가 남지 않도록 합니다. 저장하지 않은 수정에는 Decap의 이탈 확인이 적용됩니다.
- `publish_mode: simple`로 게시 내용을 main에 바로 저장합니다. 기존 미발행 브랜치는 변경 시점에 없었습니다.
- Decap 한국어 UI의 ‘게시’는 한 항목짜리 메뉴를 열기 때문에 `one-click-publish.js`가 사용자 클릭 직후 ‘지금 게시’를 실행합니다. 페이지 로드나 텍스트 입력만으로는 저장하지 않습니다.
- 로컬 프록시에서 공유 이미지 설명을 수정하고 게시 버튼 한 번으로 ‘항목 저장됨’ 표시와 파일 변경을 확인했습니다. 검증 후 원본 파일을 그대로 복원했습니다.
- 메뉴 전환 후 홈 화면·기본 정보 데이터 로딩, 미저장 이탈 확인창, 콘텐츠 검사와 빌드를 검증했습니다.
- 배포 완료 전까지 공개 홈페이지에는 이전 내용이 보일 수 있습니다.

Decap 버전 또는 관리자 언어 변경 시 한 번 클릭 게시 동작을 다시 검증해야 합니다.
