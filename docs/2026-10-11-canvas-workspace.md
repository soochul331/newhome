# 기본 화면을 캔버스 편집기로 확장 — 2026-10-11

## 사용

- `/admin/` 로그인 후 홈 화면 편집기가 바로 열립니다. 별도의 ‘홈페이지 화면에서 편집’ 버튼을 누를 필요가 없습니다.
- 왼쪽에서 기본 정보·메뉴·홈 화면·페이지·글을 선택하면 해당 영역의 화면 편집기가 바로 열립니다. 이미 만든 페이지와 글은 왼쪽에 각각 표시합니다.
- 화면의 글자를 클릭해 직접 입력하고 오른쪽 **선택 요소**에서 서식·객체 크기를 바꿉니다. 메뉴·버튼·푸터 링크는 링크 주소도 바로 바꿀 수 있습니다.
- **영역 설정**에는 해당 영역에서 관리할 수 있는 모든 기존 필드가 있습니다. 검색 설명, 테마, 날짜, 링크, 모바일 표시, 이미지, 섹션·카드 순서와 추가·삭제 등은 이곳에서 수정합니다.
- 홈에서 상단 이름·메뉴·푸터를 클릭하면 해당 설정 영역으로 전환합니다. 미저장 변경이 있으면 기존 CMS의 이동 확인 절차가 적용됩니다.
- **되돌리기 / 다시 실행**은 현재 편집 세션의 변경을 되돌립니다. **변경사항 게시**로 현재 영역을 저장·배포합니다. 다른 영역의 변경을 한꺼번에 묶어 저장하는 방식은 아닙니다.
- **양식 보기**는 기존 입력 화면으로 돌아가는 보조 기능입니다. 기본은 화면 편집입니다.

## 저장·호환

- 저장 파일과 GitHub 인증·권한은 기존 Decap CMS 방식 그대로입니다. 별도 인증, 토큰 접근, 새로운 저장 서버를 만들지 않았습니다.
- 화면 편집은 각 기존 필드의 `onChange`를 통해 CMS 초안에 반영합니다. `_canvas`는 UI 전용 선택 필드이며 콘텐츠에 저장되지 않습니다.
- 기본 정보·메뉴·페이지·글에도 서식 필드를 추가하고, 홈페이지와 편집기가 같은 서식 엔진을 사용합니다.
- 페이지·글·자유 글은 Turndown으로 화면 본문을 마크다운으로 저장합니다. 붙여넣기는 브라우저의 plaintext-only 편집을 사용하며 HTML 스크립트는 허용하지 않습니다.
- 저장 완료는 Decap의 공식 postSave/postPublish 이벤트로 확인합니다. 현재 세션에서 저장한 홈·기본 정보·메뉴는 다른 영역의 화면에도 반영합니다.
- 객체 크기는 숫자 입력 방식입니다. 자유 드래그 배치나 개별 기기별 독립 서식은 포함하지 않습니다.

## 검증

- 로컬 CMS에서 기본 진입 시 자동 열기, 홈 제목/색상 저장, 기본 정보 이름·크기·검색 설명 저장, 메뉴 이름·색상 저장, 되돌리기/다시 실행을 확인했습니다.
- 임시 페이지에서 본문 직접 입력, 제목·굵은 글자·링크의 마크다운 보존, 글꼴·크기 저장 및 실제 렌더링을 확인했습니다.
- 기존 글에서 제목·빈 본문 직접 수정, 속성 패널의 요약 수정, 날짜·외부 링크 보존과 저장을 확인했습니다.
- 테스트 콘텐츠는 원본으로 복구하고 임시 페이지는 제거합니다.
- `npm run build`, `node scripts/check-themes.js`, `node scripts/check-visual-editor.js`, `git diff --check`로 검사합니다.
