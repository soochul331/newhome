# 전체 화면 텍스트 편집

- 현재 초안의 기존 데이터 필드와 연결된 텍스트는 원래 필드에 저장한다.
- 메뉴·푸터·디자인 안내 등 나머지 텍스트는 현재 초안의 appearance.canvasTexts에 저장한다. 다른 CMS 항목으로 이동하지 않으며 한 번의 게시로 저장된다.
- 공통 VisualLayout.textTargets가 텍스트 노드를 안전한 span으로 감싼다. 테마, 영역 ID, 영역 안의 노드 위치로 키를 만든다. 사용자 문자열은 textContent로 적용하므로 HTML로 실행하지 않는다.
- 홈페이지 초안의 헤더·푸터 텍스트 편집은 다른 페이지에도 표시된다. 본문 편집은 해당 화면에 적용된다.
- 테마별 디자인 문구는 서로 다른 키를 사용한다. 템플릿의 DOM 구조를 바꾸면 해당 위치의 보조 텍스트 키도 이관해야 한다. 검색 메타 정보는 기존 기본 정보 양식에서 관리한다.
- 오른쪽 패널 420px, 가로 크기 조절 및 세로 크기 조절이 가능한 180px 이상 텍스트 입력칸을 제공한다.

검증: 로컬 CMS에서 사이트 이름·메뉴·디자인 안내를 한 초안으로 편집/게시, 재접속 후 유지 확인, 빌드된 공개 화면에서 문구와 서식 반영 확인. 테스트 콘텐츠는 복원했다. 기존 5개 테마 검사와 시각 편집기 회귀 검사 통과.
