회원가입 없이 이용하는 실습 자료입니다. 자료 확인일: 2026년 10월 15일.

## 어떤 녹음으로 연습하면 되나요?
아래 가상 대본을 직접 읽어 녹음하면 됩니다. 실제 회의 정보는 필요하지 않습니다.

> 다음 내용은 실습용 가상 회의입니다.
> 진행자: 다음 교육 모임은 토요일 오전 열 시로 제안합니다.
> 담당자: 토요일은 어렵습니다. 일요일 오후 두 시로 바꾸면 좋겠습니다.
> 진행자: 그러면 일요일 오후 두 시로 결정하겠습니다. 장소는 아직 미정입니다.
> 담당자: 안내문은 제가 금요일까지 작성하겠습니다. 게시 담당은 다음 회의에서 정하겠습니다.
> 진행자: 예산은 오늘 결정하지 않겠습니다.

## 무엇을 비교하면 되나요?
AI 요약과 원본 음성을 함께 확인합니다. 한국어 인식 설정에서 제공되는 요약 기능을 확인하고, 시간 표시를 눌러 해당 구간을 다시 듣습니다.

- 확정 일시: 일요일 오후 두 시입니다. 토요일은 처음 제안한 시간입니다.
- 안내문 작성: 담당자가 금요일까지 작성하기로 했습니다.
- 장소·게시 담당·예산: 아직 정하지 않았습니다.

이 기준은 실습 대본의 정답이며, 도구의 실제 출력 결과는 아닙니다.

## 회의록 양식은 어떻게 쓰나요?
확정 사항과 논의 중인 내용을 별도 칸에 기록합니다.

```text
회의 제목:
회의 날짜:
확정된 사항:
할 일 / 담당자 / 마감일 / 근거 음성 위치:
아직 결정하지 않은 사항:
다음 회의에서 확인할 질문:
음성과 대조한 사람 / 확인 날짜:
```

## 실제 교회 회의에는 어떻게 적용하나요?
녹음할 수 있는 회의인지 참여자와 먼저 확인하고 적용합니다. 사람 이름과 부서명은 자동 인식 결과를 다시 확인합니다. 민감한 상담 내용은 이 실습에 사용하지 않습니다.
