# 네 단계 학습 카드

- 카드 목록을 최대 4개로 확장하고 선택 입력란 `단계 표시(제목 위)`를 추가했습니다.
- 단계 표시는 제목 위 왼쪽에 13px 회색(#677080) 글씨로 표시됩니다. 비우면 렌더링하지 않습니다.
- 카드가 4개면 PC에서 2×2, 휴대폰에서 1열로 표시합니다. 기존 3개 묶음은 기존 배치를 유지합니다.
- 로컬 관리자에서 홈 화면의 for-whom 섹션에 도입문과 네 카드를 입력한 뒤 게시 버튼으로 저장했습니다. 소스 직접 편집으로 콘텐츠를 입력하지 않았습니다.
- 단계: 분별과 책임 → 질문의 기초 → 실제 활용 → 나만의 도구.
- 기존의 최근 관리자 변경(히어로·질문 문구)은 유지했습니다.
- 콘텐츠 검사와 빌드 통과. PC 2열, 휴대폰 1열, 단계 글씨 크기 및 가로 넘침 없음을 확인했습니다.
- Netlify에서 기능 배포 3c3b03e는 `Skipped due to account credit usage exceeded`로 건너뛰었습니다. 계정 사용량 문제가 해결되고 최신 main이 배포되어야 실제 관리자와 공개 홈페이지에 반영됩니다.
