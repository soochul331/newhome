# Beagle 테마 적용

- 기본 테마를 Beagle로 변경하고 관리자 화면의 테마 선택에 추가했다. 이전 5개 테마도 유지한다.
- 데모와 실제 홈페이지가 공통 레이아웃·섹션 템플릿을 사용한다. 비교 안내는 데모에서만 표시한다.
- 사용자 제공 가로형 로고는 헤더, 세로형 로고는 푸터에 배치했다. 원본 PNG를 보존하고 CSS multiply로 흰 배경을 테마 배경과 혼합한다.
- 종이 노트의 학습 단계는 기존 학습 카드 데이터를 참조하며 시각 편집기에서도 같은 항목을 편집한다.
- 기존 문의 폼, 구조화 데이터, 글 목록, 관리자 링크를 유지한다.
- 빌드, 6개 테마의 관리자 미리보기 검사, 시각 편집기 회귀 검사 통과. 모바일 가로 넘침 없음과 로고 표시 확인.
