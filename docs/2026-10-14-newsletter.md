# 뉴스레터 게시판

- 공개 목록: /newsletter/ (최신 발행일 순)
- 관리자 → 뉴스레터 → 새 뉴스레터: 제목, 발행일, 요약, 선택 이미지, 본문을 입력하고 게시.
- 공개를 끄고 저장하면 목록에서 제외하고 상세 HTML을 생성하지 않는다. 저장소 접근 권한자는 원본을 읽을 수 있으므로 비밀 자료 보관용은 아니다.
- 원본: src/newsletters/*.md. 상세 주소는 /newsletter/파일이름/.
- 최초 상태는 빈 목록이다. 실제 뉴스레터 원고는 임의로 작성하지 않았다.
- 글쓰기는 Decap 기본 Markdown 편집기와 실제 사이트 템플릿 미리보기를 사용한다.
- 이메일 구독·자동 발송 기능은 포함하지 않는다.
- 검증: node scripts/check-newsletters.js (임시 글 생성 → 최신순/상세/비공개 검사 → 삭제 및 재빌드).
