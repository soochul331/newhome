# Church AI Lab 뉴스레터 운영계획

## 확정된 목표

- 대상: AI를 사역에 실질적으로 활용하려는 목회자와 교회교육 담당자.
- 분야: 설교준비, 목회행정, 교회교육, 나만의 AI 도구.
- 하루 두 편, 한국 시간 오전 08:00와 오후 18:00.
- 게시처: https://churchailab.org/newsletter/
- 실행 도구: 사용자가 지정한 Aside 브라우저의 Routines. 현재 미등록.
- 이메일 발송은 이번 범위에 포함하지 않는다.

## 첫 주 편성안

검색량이나 독자 반응을 측정한 순위가 아니라, 홈페이지의 네 가지 활용 분야와 사용자가 정한 방향에 맞춘 제안이다.

| 순서 | 오전 8시: 활용 관점과 방법 | 오후 6시: 바로 써 보는 실습 |
|---|---|---|
| 1일 | 설교 묵상이 흩어질 때, 먼저 질문별로 모아 보세요 | 교회 회의 메모를 다음 행동으로 바꾸는 법 |
| 2일 | 소그룹 질문은 정답보다 대화를 열어야 합니다 | 같은 교육 주제를 초등부와 중고등부에 맞춰 바꾸기 |
| 3일 | 교회 공지문에 빠지기 쉬운 정보를 확인하는 법 | 행사 안내문을 문자와 주보용으로 나누어 쓰기 |
| 4일 | 설교 핵심 메시지를 한 문장으로 정리하는 연습 | 설교 숏츠 자막을 읽기 편하게 다듬는 법 |
| 5일 | 나만의 AI 도구, 반복되는 업무부터 찾으세요 | 사역 도구 제작 제안서를 한 장으로 정리하기 |
| 6일 | 교사회의 자료에 필요한 정보만 남기는 법 | 주일학교 예배 후 소그룹 활동지 초안 만들기 |
| 7일 | AI 결과물을 다시 고칠 때 기준부터 정하세요 | 다음 주 사역 준비를 위한 개인 점검표 만들기 |

## 편집 지침

- 한국어 존댓말. 한 편은 한 가지 실제 업무를 다룬다. 본문은 약 1,000~1,600자 내외를 목표로 하되 내용상 필요한 경우 조절한다.
- 독자의 상황 → 활용 관점 → 구체적인 진행 방법 → 복사할 요청문 → 확인할 결과물 순서로 구성한다. 모든 글을 똑같은 소제목으로 반복하지 않는다.
- 신학적 분별 논의보다 실질적 활용에 집중한다.
- 작성자의 실제 경험·성과·후기를 지어내지 않는다. 가상의 입력과 결과는 ‘예시’라고 표시한다.
- 도구의 현재 기능·가격·제한·인용·통계는 공식 원문을 확인하고 해당 링크와 확인 날짜를 기록한다. 확인할 수 없는 주장은 삭제한다.
- 자료에서 개인정보를 수집하거나 실제 교인의 상담·연락처 자료를 사용하지 않는다. 연습은 가상 예시로 한다.
- 근거 없는 시간 절감 수치, 유행을 과장하는 표현, 같은 의미의 도입부 반복을 제거한다.
- 최근 30편과 비교해 주제·요청문·사례가 실질적으로 겹치지 않게 한다.
- 제목·요약·본문·링크를 검수하고 정상 게시 여부를 실제 공개 페이지에서 확인한다.

## 연결 순서

1. Aside 설치 및 계정 로그인. 필요한 약관 동의와 계정 설정은 사용자가 화면에서 진행한다.
2. Aside에서 홈페이지 관리자에 로그인하고 뉴스레터 새 글 화면까지 확인한다.
3. drafts의 두 원고를 검토하고 첫 발행을 테스트한다.
4. Settings > Routines에서 08:00와 18:00 작업 두 개를 등록한다. 시간대 Asia/Seoul을 확인한다.
5. 수동 Run으로 한 차례 시험하고 목록·상세·중복 방지·발행일을 확인한다.
6. 실제 실행에 필요한 앱 실행 상태와 게시 승인 요구 여부를 확인한다. 공식 문서만으로 컴퓨터가 꺼진 상태의 실행 또는 무승인 게시를 보장하지 않는다.
