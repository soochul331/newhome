- 실제 홈페이지와 CMS 데이터는 변경하지 않는다. 별도 데모 템플릿과 데모 전용 CSS/JS만 추가한다.

## 디자인 판단
- 네이비 #102858, 블루 #6B92CC, 밝은 블루 #EAF0F9, 바탕 #F7F9FC, 본문 #52647F.
- 한국어 고딕의 큰 제목과 여백을 중심으로 구성한다. 반복 카드 대신 풀폭 작업 화면, 좌우 비대칭 스크롤 설명, 실제 도구 소개, 단계형 학습 과정, 간결한 소개와 문의를 배치한다.
- 작업 화면은 설교준비/목회행정/교회교육/나만의 AI 도구를 설명하는 데모이며, 고객 성과나 실제 앱 실행으로 표현하지 않는다.
- 문의는 현재 공개 홈페이지의 문의 양식으로 연결한다. 데모에서는 외부 양식을 제출하지 않는다.

## 모션
1. 줄 단위로 올라오는 첫 제목.
2. 요청 뒤 문서가 겹쳐지며 조립되는 활용 화면. 탭은 마우스와 방향키/Home/End로 전환.
3. 포인터에 반응하는 작은 깊이 효과(마우스 지원 환경에 한정).
4. 그림이 머무르고 설명에 따라 자료 종류가 바뀌는 스크롤 구성. 모바일에서는 고정 해제.
5. 설교 쇼츠의 파형, 영상 등장, 재생 진행선.
6. 학습 단계 순차 등장과 링크 반응.
- 자동 모션은 유한하게 재생한다. 강제 스크롤, 무한 루프, 자동 탭 전환은 없다.
- 모션 끄기, 처음부터 보기, prefers-reduced-motion 대응. 기기에서 모션 줄이기를 선택했으면 토글도 비활성화한다.
- 숨겨진 탭에서는 CSS 애니메이션을 일시 중지한다. 스크롤 갱신은 passive 이벤트와 requestAnimationFrame으로 묶는다.
- JavaScript 없이도 본문을 읽을 수 있고 첫 활용 예시가 표시된다. 검색 제외 메타 태그 적용.

- 설교준비 → 목회행정 → 교회교육 → 나만의 AI 도구 순서로 소개·예시·스크롤 설명을 통일한다.
- 홈 데이터의 활용 카드, 학습 과정, 소개, 블로그 안내, 문의 문구와 검색 설명도 같은 방향으로 변경했다.

- 설교준비는 직접 정리한 본문 메모와 흐름·적용·전달 준비를 중심으로 설명한다.

## 확장 가능한 도구 소개 영역
- 데모 제목 마지막 마침표 제거.
- 메뉴 “직접 만든 AI도구”는 /#tools로 연결하고, 데모에서는 #tools 내부 이동으로 처리한다.
- src/_data/tools.yml의 items 목록으로 도구 소개를 생성한다. name, category, tagline, description, intro_url, app_url, visual 필드를 사용한다.
- 새 항목을 추가하면 구분선으로 나뉜 소개 행이 아래로 이어진다. 소개 링크와 실행 링크는 각각 선택 사항이다.
- visual: shorts이면 파형/영상 모션을 사용한다. 다른 값 또는 생략 시 AI도구 SVG를 표시한다.
- 현재 실제 도구인 설교 숏츠 제작기만 표시하며 예정 도구를 임의로 추가하지 않는다.
- 현재는 파일 기반 목록이다. 관리자에서 도구를 추가하는 별도 양식은 아직 연결하지 않았다.
