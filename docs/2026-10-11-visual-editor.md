# 홈페이지 화면 편집 — 2026-10-11

> 이후 기본 화면과 전체 영역 편집으로 확장했습니다. 현재 사용법은 [캔버스 작업 공간](2026-10-11-canvas-workspace.md)을 참고하세요.

## 사용 방법

1. `/admin/` → 사이트 설정 → 홈 화면 → **홈페이지 화면에서 편집**.
2. 글자를 클릭해 직접 입력합니다. 오른쪽에서 고딕·명조·고정폭, 색상(색상표 또는 HEX 코드), 크기, 굵기, 정렬을 조절합니다.
3. 카드의 빈 곳을 클릭하거나 카드 글자를 선택한 뒤 **이 카드 크기 선택**을 누르면 폭·최소 높이·안쪽 여백을 조절합니다. **구획 크기 선택**으로 구획을 조절할 수 있습니다.
4. 이미지 구획은 기존 섹션 목록의 추가 메뉴에서 만듭니다. 이미지를 선택하면 폭을 조절하며 비율은 유지됩니다.
5. PC·휴대폰 버튼으로 확인한 뒤 **초안에 적용**을 누릅니다. **취소**하면 이번 화면 편집을 버립니다.
6. 관리자 상단 **게시** 버튼으로 저장·배포합니다. 화면 편집 중에는 실제 사이트에 저장하지 않습니다.

## 범위

- 첫 단계는 홈 화면의 데이터에 연결된 제목·본문·질문·단계·버튼·소개 항목·이미지 설명과 카드·구획·이미지 크기입니다.
- 노션 보드·Claude 학습 목록은 본문 카드와 같은 데이터를 수정합니다.
- 글꼴과 객체 크기는 테마 위에 적용합니다. 카드 서식은 카드 데이터 안에 저장하므로 카드 순서를 바꿔도 함께 이동합니다.
- 모바일에서 객체 폭은 화면을 넘지 않으며 글자 크기는 화면 폭에 맞춰 제한됩니다.
- 메뉴·사이트 이름·푸터는 기존 기본 정보/메뉴에서, 글 목록은 글·소식에서, 자유 글의 마크다운 본문은 기존 입력창에서 수정합니다. 테마의 고정 장식 문구는 이 단계의 직접 편집 대상이 아닙니다.
- 자유 배치·드래그 핸들·기기별 독립 서식은 다음 확장 범위입니다. 이번 단계의 크기 조절은 숫자 입력 방식입니다.

## 구현과 검증

- Decap `visualsections` 커스텀 위젯 안에 기존 list 입력창을 유지하며 전체 화면 iframe 편집기를 추가했습니다.
- 같은 Nunjucks 템플릿과 `visual-layout.js`를 실제 사이트와 편집기에 사용합니다. 입력은 일반 문자열로 저장하고 붙여넣기는 텍스트만 허용합니다. iframe 스크립트·폼 제출·링크 이동을 막습니다.
- 서버 렌더링의 서식 JSON은 HTML 속성으로 이스케이프하며, 적용 엔진은 지정된 글꼴·색상·숫자·정렬만 허용합니다.
- 로컬 CMS에서 제목·글꼴·크기·색상·노션 카드·카드 폭·높이·여백·이미지 폭을 수정하여 게시한 뒤 YAML 파일과 실제 로컬 홈페이지 반영을 확인했습니다. 재열기와 모바일 화면도 확인했습니다.
- 테스트 콘텐츠와 이미지는 원본으로 복구했으며 배포에는 포함하지 않습니다.
- `npm run build`, `node scripts/check-themes.js`, `node scripts/check-visual-editor.js`, `git diff --check` 통과.
