# 무명AI교회 PDF 실습 기록

확인일: 2026-10-16 (Asia/Seoul)

사용자가 첫 요약 질문을 제출했고 실제 응답을 확인했습니다. 행사명, 일시, 장소, 대상, 신청 마감, 참가비, 준비물, 신청·문의의 8개 항목이 업로드한 PDF와 일치했습니다. 참가비는 미정(10월 26일 별도 안내 예정)으로 표시했고 연락처와 신청 링크는 안내문에 없다고 답했습니다.

참가비 옆 인용 번호를 눌러 education-notice.pdf의 인용 세부정보가 열리는 것을 확인했습니다. 각 항목이 같은 인용 번호 1을 사용했고 넓은 본문 구간이 표시되므로 번호가 있다는 사실만으로 개별 주장의 정확성을 판단할 수 없습니다. 실제 문장과 함께 비교해야 합니다.

관찰한 장점: 짧은 안내문의 주요 정보를 표로 정리하고 원문을 같은 화면에서 확인할 수 있습니다.
관찰한 한계: 이 시험은 텍스트 PDF 1페이지 한 건입니다. 스캔 PDF·복잡한 표·여러 문서·반복 실행 정확도는 시험하지 않았습니다.

다음 단계: 보호자 안내 메시지를 만드는 두 번째 요청을 입력창에 준비했으며 아직 제출하지 않았습니다. 원고 승인이나 공개 발행은 하지 않았습니다.

## 두 번째 시험: 보호자 안내 메시지

사용자가 제출한 두 번째 질문에 6문장 안내 메시지가 생성되었습니다. 가상 실습이라는 첫 문장, 행사명·대상·일시·장소·마감·참가비 미정과 별도 안내일이 유지됐습니다. 없는 연락처나 신청 링크를 생성하지 않았고, 담당자의 보완 항목으로 연락처·신청 링크, 확정 참가비, 대여 기기, 사진 공개 동의를 분리했습니다. 실제 발송은 하지 않았습니다.

응답 끝의 추가 제안에는 원문에 없는 ‘간식 안내’가 나타났습니다. 이것은 행사에 간식이 제공된다는 답변이 아니라 다음 작업 제안이지만, 그대로 따라가면 원문 밖 내용으로 흐를 수 있다는 관찰입니다. 원고에서는 핵심 답변과 후속 제안을 구분합니다.

마지막 시험으로 무료·선착순 확정·대여 가능이라는 근거 없는 세 홍보 표현을 판단하도록 질문을 준비했습니다. 아직 제출하지 않았습니다.

## 세 번째 시험: 잘못된 홍보 표현 점검

세 표현(참가비 무료, 선착순 20명 확정, 노트북 대여 가능)을 모두 사용 불가로 판단했습니다. 원문의 미정·조건 없음에 근거를 두고 대체 문구를 제시했습니다. 실제 전체 응답을 읽어 확인했고 화면 06은 응답 하단의 선착순·대여 판단을 담았습니다. 실습 3개 완료, 사용자 최종 원고 승인은 대기입니다.
