설교 본문을 정하고 나면 묵상과 개요, 본문연구, 예화, 적용, 원고까지 할 일이 길게 이어집니다. AI에게 도움을 받으려 해도 어디까지 맡길지, 주석 인용이 정확한지 확인하는 일이 남습니다.

설교준비 도우미는 신수철 목사가 자신의 설교 준비에 쓰려고 직접 만들었습니다. 2026년 11월 1일 처치AI랩 홈페이지에 소개 페이지와 내려받기 주소를 열었습니다. 이 글은 그 소개와 설치 방법을 정리한 자료실 글입니다.

설교준비 도우미는 목회자가 자기 Claude 계정 안에서 설교 본문과 묵상에서 원고 초안까지 준비하도록 돕는 페이지입니다. 단계마다 AI가 먼저 초안을 생성하고, 목사님이 고치고 고르십니다. 주석과 인용은 실제로 연 자료에서 확인한 것만 출처로 남깁니다.

## 설교준비 도우미는 어떤 순서로 설교를 준비하나요?

본문과 묵상에서 출발해 원고 초안과 출처 확인까지 열 단계로 이어집니다. 먼저 설교 본문을 정하고, 그 본문을 읽으며 마음에 닿은 것을 적습니다. 묵상이 아직 없으면 중심 메시지 한 줄로 시작할 수 있습니다.

그다음 AI가 묵상에서 설교 방향을 몇 가지 제안하고, 고른 방향으로 개요를 씁니다. 이어서 본문연구, 청중과 분량, 예화, 적용을 차례로 다듬습니다.

마지막으로 지금까지의 재료로 원고 초안을 쓰고, 원고에 쓴 사실과 성경 구절을 하나씩 확인해 각주를 답니다. 어느 단계든 되돌아가 고칠 수 있습니다.

준비 중인 설교와 지난 설교는 목사님 계정에 남아 다음에 이어서 쓸 수 있습니다.

## AI가 쓴 인용은 어떻게 확인하나요?

실제로 연 자료에서 글자 그대로 확인한 인용만 출처로 남기고, 확인하지 못한 내용은 **'확인 필요'로 표시합니다.** 성경 구절은 대한성서공회 개역개정 읽기 화면으로 확인할 수 있습니다.

가지고 계신 주석·설교집 PDF 폴더를 연결하면, 본문연구 단계에서 그 본문에 맞는 책을 1~3권 골라 쪽 번호와 함께 인용합니다. 스캔한 PDF도 글자 인식으로 읽을 수 있습니다. 주석의 글 자체는 페이지에 싣거나 게시하지 않습니다.

교리의 기준은 성경을 최종 권위로 삼고, 예장합동 헌법의 교리표준인 웨스트민스터 신앙고백과 대·소요리문답을 따릅니다. 이단·사이비로 결의된 단체의 자료는 어떤 출처로도 쓰지 않습니다.

## 설치하려면 무엇이 필요한가요?

Claude Pro 이상 요금제와 Claude 데스크톱 앱, Node.js 18 이상, 인터넷 연결이 필요합니다. Node.js는 출처 확인 도구와 주석 도구가 쓰며, nodejs.org의 LTS 판이면 됩니다.

주석 PDF 폴더와 NAVER API HUB 검색 키는 선택입니다. 검색 키는 '웹에서 찾기'와 '시사 예화 찾기'에 씁니다.

파일은 무료로 내려받습니다. AI 사용량은 목사님 각자의 Claude 요금제에서 나가고, 따로 내는 요금은 없습니다.

macOS와 Windows 11에서 설치, 주석 도구 연결, 서재 주석 읽기, 스캔한 PDF 글자 인식, 온라인 주석 읽기까지 확인을 마쳤습니다. Windows 11 확인은 2026년 10월 29일부터 30일까지 했습니다.

## 내려받은 파일은 어떻게 설치하나요?

zip 파일을 풀고, 안에 든 스킬 폴더 9개를 내 컴퓨터의 Claude 스킬 폴더에 복사하면 됩니다. 먼저 홈페이지 내려받기 주소(https://churchailab.org/sermon-helper/download)에서 zip 파일을 받아 풉니다. 안에는 스킬 폴더 9개와 설치안내.md, 같은 내용의 설치안내.txt가 들어 있습니다.

그다음 설치안내에 적힌 복사 명령 그대로 스킬 폴더를 옮깁니다. 이어서 Claude 데스크톱 앱의 Code 화면에서 설교를 모아 둘 폴더를 열고 "설교준비 도우미 페이지 만들어 줘"라고 말합니다. 그러면 내 계정에 나만의 비공개 페이지가 만들어집니다.

주석 도구를 쓰려면 "주석 도구 등록 방법 알려 줘"라고 말합니다. 안내대로 앱 설정에 한 항목을 넣은 뒤 앱을 완전히 종료했다가 다시 엽니다.

이 글을 쓰는 2026년 11월 1일 기준 최신 판은 2026년 10월 31일 판(v0.1.5)입니다. 홈페이지 내려받기 주소에는 언제나 최신 판이 있고, 어느 판인지는 zip 안의 VERSION.txt로 알 수 있습니다. 새 판이 나오면 같은 방법으로 폴더를 덮어쓰고 "설교준비 도우미 페이지 새로 만들어 줘"라고 하면 됩니다. 써 두신 설교는 그대로 남습니다.

## 내 설교와 자료는 어디에 남나요?

준비한 설교는 목사님의 Claude 계정에 저장되고, 페이지는 목사님만 보는 비공개로 만들어집니다. 연결한 주석 폴더와 책에서 뽑은 글, 웹 검색 키는 목사님 컴퓨터에만 남습니다.

지난 설교문을 올려 '나의 설교 스타일'을 익히게 하면 원고 초안이 목사님의 말투를 따릅니다. 설교문 전체는 저장하지 않고, Claude가 정리한 스타일만 남깁니다.

다른 목사님께는 페이지 링크 대신 홈페이지 소개 페이지나 zip 파일을 전해 주세요. 각자 자기 계정에 자기 페이지를 만듭니다.

## 오늘 해볼 수 있는 일

설치를 마치셨다면 Claude 데스크톱 앱의 Code 화면에서 설교 폴더를 열고, 아래 문장을 그대로 말해 보세요.

> 설교준비 도우미 페이지 만들어 줘

페이지가 열리면 다음 주일 본문을 적고, 묵상 한 줄에서 시작해 보세요. 천천히 가도 괜찮습니다.

## 자주 묻는 질문

질문. Claude 무료 요금제로도 쓸 수 있나요? 답. 쓸 수 없습니다. Free 요금제에는 Claude Code가 없어서 Pro 이상 요금제가 필요합니다.

질문. AI가 설교를 대신 써 주나요? 답. 초안을 쓰는 일을 맡깁니다. 설교의 방향을 고르고, 문장을 고치고, 무엇을 남길지 정하는 일은 목사님이 합니다.

질문. 주석 PDF가 없어도 쓸 수 있나요? 답. 쓸 수 있습니다. 주석 PDF 폴더 연결은 선택이며, 내 주석을 본문연구에 쓰고 싶을 때 연결합니다.

설교준비 도우미는 초안을 쓰는 일은 AI에게 맡기고, 본문 앞의 묵상과 무엇을 전할지 정하는 판단은 목회자가 지키도록 만든 도구입니다.
