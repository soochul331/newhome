# NotebookLM으로 PDF 요약하기: 인용으로 원문까지 확인하는 방법

> 편집용 정보: 검토 대기 / 공식 자료 기반 초안 / 실제 실습 미완료 / 검색량 미측정 / 네이버 미발행.
> 아래 본문부터 네이버 원고입니다. 자료 링크와 실습 결과를 확인한 뒤 승인해 주세요.

NotebookLM은 PDF를 추가한 뒤 내용을 질문하고, 답변에 달린 인용으로 원문을 확인할 수 있는 도구입니다. 긴 문서를 읽을 때는 요약의 길이보다 날짜와 조건이 정확하게 남았는지를 먼저 살펴보세요.

예를 들어 교회 교육 안내문에서 신청 마감은 목요일인데 모임 시간인 토요일만 남았다면 신청자에게 필요한 정보가 빠진 것입니다. 일반 업무의 일정표나 행사 안내문에서도 같은 문제가 생깁니다.

이 글은 Google 공식 도움말을 확인해 정리한 사용 가이드입니다. 직접 업로드해 정확도나 시간 절약을 측정한 후기는 아닙니다.

## PDF를 넣고 질문할 수 있나요?
PDF를 소스로 추가한 뒤 문서 내용을 질문할 수 있습니다. Google 공식 도움말은 소스 추가와 선택한 자료를 바탕으로 한 채팅을 안내합니다. 도움말 경로와 일부 명칭은 Gemini Notebook으로 표시되므로 실제 계정 화면의 서비스명과 메뉴를 함께 확인해 주세요.

처음에는 공유 권한이 있는 짧은 자료가 좋습니다. 문서 여러 개를 한꺼번에 넣기보다 자료 하나에서 날짜와 조건을 제대로 찾는지 확인해 보세요. 교회에서는 교육 일정표나 공개 행사 안내문으로 시작할 수 있습니다.



![짧은 PDF를 준비합니다 — 실제 교인 정보 없이 가상 안내문으로 시작합니다.](visuals/01-pdf-summary/01-prepare.png)

*그림 1. 실제 교인 정보 없이 가상 안내문으로 시작합니다.*

## PDF 요약은 어떤 순서로 시작하나요?
짧은 문서 하나를 추가하고, 확인할 항목을 지정해 질문합니다.

1. 공식 도움말의 서비스 링크에서 Google 계정으로 접속합니다.
2. 노트북을 만들거나 기존 노트북을 엽니다.
3. 소스 추가 기능으로 공유 권한이 있는 PDF를 넣습니다.
4. 질문에 사용할 소스를 선택하고 아래 요청문을 입력합니다.
5. 답변의 인용을 눌러 해당 문맥과 결과를 대조합니다.



![PDF를 소스로 추가합니다 — 메뉴 위치와 명칭은 실제 계정 화면에서 확인합니다.](visuals/01-pdf-summary/02-add-source.png)

*그림 2. 메뉴 위치와 명칭은 실제 계정 화면에서 확인합니다.*

메뉴 이름과 위치는 계정과 기기에 따라 다를 수 있습니다. 처음 연습할 때는 홈페이지의 가상 안내문을 PDF로 저장해 사용해 보세요. 실제 교인 명단이나 상담 자료는 이 연습에 필요하지 않습니다.

## 어떤 질문부터 하면 좋을까요?
요약과 함께 근거를 요청하면 검토할 위치를 찾기 쉽습니다.

```text
업로드한 문서만 근거로 답해 주세요.
핵심 내용을 항목별로 요약하고 각 항목에 근거 인용을 붙여 주세요.
일시, 장소, 준비물, 신청 마감, 담당자, 비용을 따로 정리해 주세요.
문서에 없는 정보는 '문서에 없음'으로 표시해 주세요.
확정된 내용과 아직 정하지 않은 내용을 구분해 주세요.
```



![요약과 근거를 함께 요청합니다 — 전체 요청문은 본문과 실습 자료에서 복사할 수 있습니다.](visuals/01-pdf-summary/03-ask.png)

*그림 3. 전체 요청문은 본문과 실습 자료에서 복사할 수 있습니다.*

이어 일시, 장소, 준비물, 신청 마감, 담당자, 비용을 구분해 달라고 요청해 보세요. 예를 들어 원문에 ‘회비 미정’이라고 적혀 있다면 결과에도 미정으로 남아야 합니다. 이를 무료라고 바꾸면 잘못된 요약입니다.

## 인용이 있으면 그대로 믿어도 되나요?
인용은 원문을 확인하는 출발점입니다. 답변의 인용을 눌러 실제 문맥을 읽고, 요약의 표현이 원문보다 강해지지 않았는지 살펴보세요. ‘검토 중’이 ‘확정’으로 바뀌거나, 조건부 일정에서 조건이 빠지는 경우를 특히 확인합니다.

표가 많거나 스캔 상태가 좋지 않은 문서는 추출 결과도 점검해야 합니다. 원문이 제대로 읽히지 않았다면 질문을 바꾸기 전에 입력 자료부터 확인하는 편이 좋습니다.



![인용을 열어 원문과 비교합니다 — 가상 비교 예시입니다. 실제 서비스의 실행 결과가 아닙니다.](visuals/01-pdf-summary/04-check-citation.png)

*그림 4. 가상 비교 예시입니다. 실제 서비스의 실행 결과가 아닙니다.*

## 교회 안내문으로 무엇을 확인하면 되나요?
확정된 사실과 미정인 내용을 구분했는지 확인합니다.

홈페이지 실습 안내문에는 모임 시간, 장소, 준비물, 신청 마감, 담당자와 회비 조건이 들어 있습니다. 아래 표는 그 가상 안내문을 사람이 읽어 정리한 확인 기준이며 도구의 실제 출력이 아닙니다.

| 확인 항목 | 원문 기준 | 수정이 필요한 예 |
|---|---|---|
| 모임 일시 | 토요일 오전 열 시 | 신청 마감과 혼동한 경우 |
| 신청 마감 | 목요일 | 마감일을 생략한 경우 |
| 회비 | 아직 정하지 않음 | 무료라고 바꾼 경우 |
| 장소 | 교육관, 변경 시 별도 안내 | 변경 조건을 빠뜨린 경우 |



![빠진 조건과 미정 정보를 확인합니다 — 원문과 다른 표현은 수정한 뒤 공유합니다.](visuals/01-pdf-summary/05-review.png)

*그림 5. 원문과 다른 표현은 수정한 뒤 공유합니다.*

일반 독자도 독서 모임이나 지역 행사 안내문으로 같은 연습을 할 수 있습니다. 문서 내용이 바뀌면 확인 기준도 다시 작성해야 합니다.

## 누구에게 적합한가요?
자료를 읽은 뒤 근거를 다시 확인하는 분에게 활용 후보가 됩니다. 교육 담당자라면 안내문을 정리하고 빠진 정보를 찾는 데 시험해 볼 수 있습니다. 반면 원문 확인 없이 중요한 결정을 내리려는 용도로는 권하지 않습니다.

무료 사용 범위와 업로드 제한은 계정과 공식 안내에서 확인해야 합니다. 이 글에서는 확인하지 않은 계정의 사용량이나 유료 전환 필요성을 단정하지 않습니다.

## 자주 묻는 질문
**문서에 없는 질문에도 답을 맡겨도 되나요?** 자료 안에서 답할 수 있는 질문부터 시작하고, 근거가 없으면 없다고 표시하도록 요청하세요.

**성경공부 자료에도 적용할 수 있나요?** 자료의 문장을 찾고 정리하는 작업부터 적용할 수 있습니다. 해석의 타당성을 자동으로 검증해 준다는 뜻은 아닙니다.

## 이번 준비에서 확인한 사항 — 본문에 붙이지 않습니다
- Google 공식 안내에서 PDF 추가, 소스 선택과 인용 문맥 확인을 재확인했습니다.
- 공식 도움말의 일부 명칭은 Gemini Notebook입니다. 모든 계정의 전환 시점을 단정하지 않았습니다.
- 공개 실습 페이지와 텍스트 다운로드의 HTTP 응답 및 가상 안내문·요청문 내용을 확인했습니다.
- 검색 결과에 PDF 요약·인용 확인 관련 가이드가 존재합니다. 이는 주제와 검색 의도의 참고 신호이며 검색량 또는 유입 규모 측정이 아닙니다.
- 이번 글의 제공 가치는 가상 교회 안내문의 확인 기준과 미정 정보·마감 조건을 검토하는 실습입니다.
- 실제 서비스 로그인·PDF 업로드·모델 출력 확인은 수행하지 않았습니다. 실제 결과 화면과 후기는 아직 없습니다.
