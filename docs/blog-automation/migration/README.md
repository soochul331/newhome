## 확인한 내용

각 이관 글에 직접 제작한 대표 도식 1장과 캡션, 기사 출처·확인일, 최초 작성일·이관 안내를 넣었습니다. 기사 원문과 주요 사실을 직접 열어 확인하고 긴 인용을 정리했습니다. 실제 도구 사용 후기로 바꾸지 않았습니다. 본문과 의견의 흐름을 유지하며 긴 문단을 나누고 질문·답변을 덧붙였습니다.

관련 칼럼 링크는 먼저 발행한 네이버 글의 실제 공개 URL로 교체했습니다. src/columns/의 원본은 유지했습니다. 공개 글의 제목·본문 끝·대표 이미지와 편집기 모바일 배치를 확인했습니다. 네이버 공개 출력에서 이미지 alt는 제거되지만 본문의 도식 캡션은 유지됩니다.

홈페이지 변경은 PR #7의 검토 브랜치에서만 준비 중입니다. RSS 동기화와 로컬 카드 미리보기 갱신은 홈페이지 공개 배포 완료를 뜻하지 않습니다.
