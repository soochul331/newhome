# 홈페이지 로컬 최종 검토

검토 대상: `/motion-preview/`, 연결된 `/sermon-shorts/`, 공유 데이터와 하단 영역.
실제 홈페이지로 전환하거나 배포하지 않았습니다.

## 반영한 정리
- 도구 설명의 ‘메세지’를 표준 표기 ‘메시지’로 통일.
- 모바일 문의 버튼의 글자 하나가 다음 줄로 떨어지던 문제 수정.
- 소개와 홈페이지의 핵심 메시지 분석·구간 선택·숏츠 제작 흐름, 네 가지 활용 영역, 기관 소속과 직함의 일관성 확인.

## 확인 결과와 범위
- 빌드 및 콘텐츠 검사, 기존 테마 검사, 기존 관리자 편집 검사 통과.
- 브라우저에서 탭의 키보드 방향키 전환 및 단일 패널 표시 확인.
- 모션 끄기 시 읽기 요소가 숨겨지지 않는 것을 확인.
- 모바일 375px 설정에서 가로 넘침 없음, 문의 버튼 줄바꿈 개선 확인.
- 검사한 페이지에서 이미지 로딩 실패, 내부 앵커 대상 누락, 콘솔 오류 없음.
- 운영체제 모션 감소 설정과 페이지 비활성화 시 일시정지는 코드에서 확인. 운영체제 설정을 바꾸는 실기 테스트는 수행하지 않음.
- 외부 기관 링크는 주소를 유지했으며 기관 사이트의 가용성은 보장하지 않음.

## 개성을 높이는 다음 개선 제안
효과를 일괄 추가하기보다 ‘사역의 생각이 결과물로 바뀌는’ 탭 장면을 대표 모션으로 삼습니다.
설교준비는 묵상에서 설교 개요로, 목회행정은 일정에서 문서로, 교회교육은 주제에서 활동·나눔 질문으로, AI 도구는 작업 순서에서 도구로 변하는 짧은 장면을 권합니다.
현재 구현은 아이콘과 종이 조립 효과이며 실제 AI 생성 기능이 아닙니다. 제안한 상세 변환 모션은 아직 구현하지 않았습니다.

## 실제 홈페이지 전환 때 필요한 작업
1. 데모 화면을 실제 루트 페이지에 연결하고 데모 툴바·noindex 설정을 제거.
2. 문의 영역에 기존 실제 문의 양식을 연결. 현재 데모의 `https://churchailab.org/#contact` 링크를 그대로 옮기면 자기 섹션으로 돌아오므로 수정 필수.
3. 소개 페이지의 `/motion-preview/` 이동을 실제 홈페이지 앵커로 변경.
4. 고정된 문구·프로필·도구 데이터와 기존 CMS/화면 편집의 연결을 점검하고 새 홈페이지에서도 관리 가능하도록 연결. 기존 관리자 검사 통과만으로 새 레이아웃 편집 지원이 확인된 것은 아님.
5. 전환 후 모바일·문의 동작·메타데이터·사이트맵을 확인하고 배포 후 실제 도메인에서 검증.

## 후속 반영: 활용별 변환 모션 (studio-19)
- `lab-transformation.njk`에 묵상→설교 개요, 일정→행정 문서, 주제→소그룹 활동지, 반복 작업→사역 도우미 예시를 구현했습니다.
- 탭 선택 또는 최초 영역 진입 시 약 3초간 한 번 재생하고 최종 결과물을 표시합니다. 실제 AI 생성 화면이 아니라는 안내를 함께 표시합니다.
- 기존 아이콘은 스크롤 영역 연동을 위해 DOM에 유지하고 탭 결과물에서는 숨겼습니다.
- 모션 끄기 시 입력 오버레이는 숨기고 결과물을 즉시 표시하는 것을 브라우저에서 확인했습니다. 모션 감소 설정에 대한 CSS 처리도 포함합니다.
- 빌드·콘텐츠 검사·diff 검사 통과. 모바일 375px 설정에서 가로 넘침 없음. 로컬에만 반영했습니다.

## 운영 홈페이지 및 관리자 전환
- 루트 `/`를 새 모션 스튜디오로 전환. 기본 정보의 `homepage_layout`에서 기존 레이아웃으로 되돌릴 수 있습니다.
- 공개 홈페이지에서 데모 툴바를 제거하고 모션 켜기/끄기는 하단에 유지했습니다. 운영 페이지의 noindex는 제거했으며 비교 페이지에는 유지합니다.
- 기존 Netlify `contact` 양식 이름·필드·완료 경로를 유지해 문의 섹션에 직접 연결했습니다. 실제 문의 제출은 테스트하지 않았습니다.
- 설교 숏츠 소개에서 홈으로 돌아가는 링크는 실제 홈페이지 앵커로 변경했습니다.
- 관리자와 운영 홈페이지는 `studio-home.njk`를 공유합니다. 홈 화면의 모션 스튜디오 문구·프로필과 도구 목록을 관리 필드로 추가했습니다. 주요 문구는 원본 데이터와 직접 연결하고 나머지 고정 문구는 기존 화면 텍스트 재정의 기능을 유지합니다.
- 실제 관리자에서 제목을 직접 수정하고 관리 필드 동기화를 확인한 뒤 원래 문구로 복원했습니다. 시험 수정은 게시하지 않았습니다.
- 원격 `71c4578`의 영상 파일 업로드 및 2시간 분석 제한 안내를 보존했습니다.
- `check-studio.js`에 운영/CMS 렌더 공유, 문구·도구 변경, 이스케이프, 실제 문의 양식, 홈 이동 경로 검사를 추가했습니다.
