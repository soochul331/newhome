# 홈페이지 실무 활용 중심 개편 · 2026-10-13

## 사용자 결정
- 신학적 분별 중심의 소개와 문구를 제거하고 실제 사역에서 AI를 쓰는 방법에 집중한다.
- Beagle 디자인과 Church AI Lab 로고를 유지한다.

## 내용과 구성
- 첫 문장: “AI를 사역에 쓰는 법, 함께 배웁니다.”
- 교회교육 자료, 설교·강의 준비, 반복 업무를 돕는 AI 도구의 세 활용 분야를 제시한다.
- 첫 화면에 세 분야를 클릭하거나 방향키로 전환하는 활용 흐름 예시를 넣는다. 실제 고객 사례나 성과로 표현하지 않는다.
- 학습 과정은 활용할 일 찾기 → 질문하기 → 자료 만들기 → 나만의 도구로 정리한다.
- 소개는 기존 경력과 직접 만든 도구 등 확인된 사실만 사용한다. 기존 블로그 글 제목과 링크는 유지한다.
- 강의·컨설팅 문의를 주요 행동으로 연결한다.
- 예시의 문구는 CMS와 홈페이지 직접 편집 화면에서 수정할 수 있다.
