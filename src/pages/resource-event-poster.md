회원가입 없이 이용하는 실습 자료입니다. 자료 확인일: 2026년 10월 15일.

## 디자인 전에 무엇을 정하면 되나요?
행사 정보를 먼저 확정하면 문구 수정과 누락을 줄이는 데 도움이 됩니다.

```text
행사명:
대상:
일시:
장소:
준비물:
참가비 또는 비용 안내:
문의 방법:
신청 링크:
```

모르는 정보는 비워 두고, 디자인 생성 과정에서 임의로 채우지 않도록 합니다.

## 디자인 초안은 어떻게 요청하나요?
원하는 정보의 순서와 여백을 구체적으로 요청합니다. 아래 요청문은 디자인 구성을 위한 예시이며 실제 생성 결과는 아닙니다.

```text
Create a simple portrait event poster for a community workshop.
Use a large title, a clear date and location, and generous spacing.
Use editable placeholder text. Do not invent event details.
Use only free elements and avoid photographs of real people.
```

사용 가능한 생성 기능은 계정에서 확인합니다. 해당 기능을 쓸 수 없다면 기본 포스터 템플릿에 행사 정보를 직접 넣어도 됩니다. 한글 행사명과 일시·장소는 직접 편집해 확인합니다.

## 저장 전에 무엇을 확인하나요?
편집 화면과 내려받은 파일을 모두 확인합니다.

- 행사명, 요일, 시간, 장소가 확정 정보와 일치하는지 확인합니다.
- 휴대전화 화면에서도 핵심 문구가 읽히는지 확인합니다.
- 배경과 글자가 구분되고 글자가 잘리지 않는지 확인합니다.
- 유료 요소 표시나 워터마크가 남지 않았는지 확인합니다.
- 신청 링크가 실제로 열리는지 확인합니다.

## 교회교육 안내에도 쓸 수 있나요?
행사 정보와 대상을 바꾸어 사용할 수 있습니다. 이 양식은 디자인 완성도나 자동 생성 품질을 보장하지 않으며, 배포 전에 담당자가 내용을 확인해야 합니다.
