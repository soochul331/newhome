설교 준비 스킬 설치 안내 (목회자용)
===================================

이 스킬 묶음을 설치하면 Claude가 설교 준비를 차례로 돕습니다: 본문연구 → 설교 방향 → 개요 → 원고.
가장 큰 특징은 출처입니다.
- 주석·인용·역사 배경은 Claude가 실제로 연 웹 페이지에서 글자 그대로 확인한 것만 '출처 있음'으로 남깁니다.
- 확인하지 못한 내용은 '확인 필요'로 표시합니다.
- 성경 구절은 대한성서공회 개역개정 읽기 화면 링크로 확인할 수 있습니다.

0. 처음 쓰시는 분 — 설교준비 도우미 페이지 만들기
-------------------------------------------------

설교준비 도우미는 Claude 안에서 여는 페이지(비공개 아티팩트)입니다. 페이지 파일(html)만 내려받아 열면 AI·저장·주석 도구가 움직이지 않습니다. 그래서 목사님마다 자기 Claude 계정에 자기 도우미 페이지를 한 번 만들어 씁니다. 받으신 zip에는 스킬과 이 안내만 들어 있고, 다른 사람의 설교나 페이지 주소는 들어 있지 않습니다.

준비물

- Claude Pro 이상 요금제 / 설명: Free 요금제에는 Claude Code가 없습니다(아래 1번).
- Claude 데스크톱 앱 / 설명: 페이지를 만드는 Code 화면과, 주석 도구가 연결된 채로 페이지를 여는 곳입니다.
- Node.js 18 이상 / 설명: 출처 확인 도구와 주석 도구가 씁니다(아래 1번).
- 인터넷 연결 / 설명: 웹 검색과 출처 확인에 필요합니다.
- (선택) 주석 PDF 폴더 / 설명: 가지고 계신 주석을 본문연구에 쓰려면(3-1).
- (선택) NAVER API HUB 키 / 설명: '웹에서 찾기'와 '시사 예화 찾기'를 쓰려면(3-4).

순서

1. 받은 zip(sermon-helper-<날짜>-v<버전>.zip)을 풉니다. 이런 것이 나옵니다.
   - skills/ 안의 폴더 9개
   - 설치안내.md (이 안내)
   - 설치안내.txt (같은 내용, 메모장용)
   - .env.example (네이버 키를 넣을 자리. 이름이 점으로 시작해서 Finder·탐색기에서 숨은 파일로 보일 수 있습니다)
   - VERSION.txt (받은 판의 버전·날짜가 적힌 파일)
2. skills/ 안의 폴더 9개를 ~/.claude/skills/(Windows는 C:\Users\<사용자이름>\.claude\skills\)에 복사합니다. Mac 터미널 명령과 Windows PowerShell 명령이 아래 2번 '설치'에 있습니다.
3. Claude 데스크톱 앱의 Code 화면에서 설교를 모아 둘 폴더(예: 문서/설교)를 열고 이렇게 말씀하세요.
     설교준비 도우미 페이지 만들어 줘
   - Claude가 페이지를 만들어 목사님 계정의 비공개 아티팩트로 게시하고 링크를 드립니다.
   - 페이지 주소는 그 폴더의 sermons/hub.json에 적어 둡니다. 다음에도 같은 폴더에서 Claude Code를 여세요. 이 파일로 같은 페이지를 찾습니다.
4. 이어서 이렇게 말씀하세요.
     주석 도구 등록 방법 알려 줘
   - Claude가 설정 파일(claude_desktop_config.json)의 위치와 넣을 "sermon-sources" 항목을 보여 드립니다. 목사님이 직접 그 파일에 넣습니다(자세한 것은 3-3).
5. Claude 데스크톱 앱을 완전히 종료했다가 다시 엽니다.
6. 데스크톱 앱에서 3번에 받은 링크로 도우미 페이지를 엽니다. 주석 도구를 처음 부를 때 앱이 허락을 물을 수 있습니다.
7. (선택) 3-1처럼 주석 폴더를 연결하고, 3-4처럼 네이버 키를 넣습니다.

새 버전 받기

어느 판인지는 zip 안 VERSION.txt(또는 파일 이름의 v번호)로 알 수 있습니다.

1. 새 zip을 풀고, 그 안의 폴더 9개로 ~/.claude/skills/ 안의 같은 이름 폴더를 덮어씁니다. 명령은 아래 2번 '설치'와 같습니다(zip을 푼 폴더를 먼저 확인하고 복사합니다).
2. 처음 페이지를 만든 그 폴더에서 Claude Code를 열고 이렇게 말씀하세요.
     설교준비 도우미 페이지 새로 만들어 줘
   - Claude가 sermons/hub.json에 적힌 주소에 새 페이지를 다시 게시합니다. 주소는 그대로입니다.
   - 바꾸기 전에 Claude가 지금 페이지를 새 판으로 바꿀지 한 번 묻습니다. 써 두신 설교 글·지난 설교 목록·설교 스타일은 그대로 남습니다.
3. Claude 데스크톱 앱을 완전히 종료했다가 다시 엽니다(주석 도구의 새 기능이 보이게).
- 네이버 키(~/.claude/.env.local)와 연결한 주석 목록(~/.claude/.local/commentary/)은 skills 폴더 밖에 있어서 덮어써도 그대로 남습니다.

두 번째 컴퓨터에서 쓰기 (같은 Claude 계정)

1. 그 컴퓨터에도 위 1~2번처럼 zip을 풀어 폴더 9개를 복사합니다.
2. Claude Code에서 설교 폴더를 열고 "설교준비 도우미 페이지 만들어 줘"라고 하시면, Claude가 이 계정에 이미 있는 도우미 페이지를 찾아 그대로 쓸지 묻습니다. 그대로 쓰기를 고르세요.
   - 써 두신 초안과 지난 설교 목록은 페이지 안에 저장돼 있어서, 그대로 쓰면 두 컴퓨터에서 같은 내용이 보입니다. 새로 만들면 빈 페이지가 하나 더 생깁니다.
3. 주석 도구 등록(4~5번)과 주석 폴더·네이버 키(3-1·3-4)는 컴퓨터마다 따로 합니다.

미리 알아 두실 것

- Windows: 2026-10-29~30에 실제 Windows 11 PC에서 설치·주석 도구 연결·서재 주석 읽기·스캔한 PDF 글자 인식·온라인 주석 읽기까지 확인을 마쳤습니다(3-2).
- 사용량: 도우미 페이지와 Claude Code가 쓰는 AI 사용량은 목사님 각자의 요금제에서 나갑니다.
- 비공개: 페이지는 목사님만 보는 비공개로 만들어집니다. 링크를 다른 분께 보내도, 초대하지 않은 분이 페이지에 쓴 글은 저장되지 않습니다. 다른 목사님께는 링크 대신 이 zip을 드려 각자 페이지를 만들게 하세요.

1. 필요한 것
------------

- Claude Pro 이상 요금제 (Pro · Max · Team · Enterprise) / 설명: Free 요금제에는 Claude Code가 없습니다.
- Claude Code / 설명: Claude 데스크톱 앱의 Code 화면, 또는 터미널의 claude 명령. claude.ai 웹 채팅에서 쓰는 방법은 아직 확인하지 않았습니다(출처 확인 도구가 내 컴퓨터의 Node와 인터넷 접속을 씁니다).
- Node.js 18 이상 / 설명: 출처를 다시 받아 확인하는 작은 프로그램(check.mjs)이 씁니다. 터미널에서 node --version을 쳐서 v18 이상이 나오면 됩니다. 없으면 https://nodejs.org 에서 LTS 판을 설치하세요. 다른 프로그램은 설치하지 않아도 됩니다.
- 인터넷 연결 / 설명: 웹 검색과 출처 확인에 필요합니다.

설교 준비에 드는 Claude 사용량은 각자의 요금제에서 나갑니다. 따로 내는 API 요금은 없습니다.

2. 설치 (5분)
-------------

zip을 푼 폴더의 skills/ 안에서 아래 폴더들을 찾습니다. sermon-sources와 sermon-commentary는 꼭 함께 설치합니다.

    sermon-sources       ← 출처 규칙과 확인 도구 (반드시 함께 설치)
    sermon-exegesis      ← 본문연구
    sermon-angles        ← 설교 방향
    sermon-outline       ← 개요
    sermon-manuscript    ← 원고
    sermon-illustration  ← 예화 찾기 (선택)
    sermon-application   ← 적용 만들기 (선택)
    sermon-page          ← 설교준비 도우미 페이지 만들기, 설교 페이지 게시, '지난 설교' 목록
    sermon-commentary    ← 주석 도구 (내 주석 PDF 읽기, 데스크톱 앱 연결 — 반드시 함께 설치)

폴더들을 통째로 아래 위치에 복사합니다. 폴더 이름을 바꾸지 마세요.

- Mac: ~/.claude/skills/ (홈 폴더 안의 숨은 폴더 .claude 안의 skills)
      Z="<zip을 푼 폴더>"
      ls "$Z/skills/sermon-commentary/SKILL.md"
  파일 이름(…/SKILL.md)이 나올 때만 다음 줄을 실행하세요.
      mkdir -p ~/.claude/skills
      cp -R "$Z"/skills/sermon-* ~/.claude/skills/
- Windows: C:\Users\<사용자이름>\.claude\skills\ 에 같은 폴더들을 복사합니다. PowerShell에서:
  - PowerShell은 관리자 권한으로 열지 마세요(프롬프트가 C:\windows\System32로 시작하면 관리자 창입니다. 관리자 창에서는 Google Drive 같은 클라우드 드라이브가 보이지 않을 수 있습니다).
      $d = "<zip을 푼 폴더>"
      Test-Path "$d\skills\sermon-commentary"
  True가 나올 때만 다음 줄을 실행하세요.
      New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills"
      Copy-Item -Recurse -Force "$d\skills\*" "$env:USERPROFILE\.claude\skills\"
      Get-ChildItem "$env:USERPROFILE\.claude\skills"
  마지막 줄에 sermon-으로 시작하는 폴더 9개가 보이면 됩니다(Mac은 ls ~/.claude/skills).

확인: Claude Code를 새로 열고 / 를 치면 sermon-exegesis 등이 목록에 보입니다.

  참고
  - 이 위치(~/.claude/skills)의 스킬은 그 컴퓨터의 Claude Code에서만 쓰입니다. 데스크톱 앱의 Cowork나 클라우드 세션에는 실리지 않습니다.
  - 한 폴더(교회 설교 폴더 등)에서만 쓰고 싶으면, 그 폴더 안에 .claude/skills/를 만들어 거기에 복사해도 됩니다.

3. 설교 하나 준비하기
---------------------

1. 설교를 모아 둘 폴더를 하나 정합니다(예: 문서/설교). 그 폴더에서 Claude Code를 엽니다.
   - 데스크톱 앱: Code 화면에서 폴더 선택
   - 터미널: cd ~/Documents/설교 && claude
2. 이렇게 말씀하시면 됩니다.
     요한복음 15:1-11로 25분 설교를 준비하고 싶어요. 묵상: 우리는 예수님 곁에 붙어 있어야 좋은 열매를 맺을 수 있다.

   Claude가 sermon-exegesis를 불러 본문연구부터 시작합니다. 직접 부르려면 /sermon-exegesis라고 치세요.
3. 단계마다 결과를 보여 드립니다.
   - 방향: 세 가지 중 하나를 고르시거나 직접 적어 주세요.
   - 개요: 고치실 곳을 말씀하시면 반영합니다.
   - 원고: 길이(15·25·35분)와 대상(장년·청년 등)을 정하시면 섹션별로 씁니다.
   - 예화(선택): "예화 찾아 줘"라고 하시면 개요에 맞는 이야기·통계·인용·역사 사건을 찾아 출처를 확인합니다. 출처를 찾지 못한 예화는 '확인 필요'로만 보여 드립니다. 지어낸 이야기를 사실처럼 쓰지 않습니다.
   - 적용(선택): "적용 만들어 줘"라고 하시면 대지마다 이번 주에 해 볼 수 있는 적용을 본문 구절과 함께 드립니다.
4. 결과는 sermons/<본문>/ 폴더에 파일로 남습니다.
   - exegesis.json 본문연구 · angles.json 방향 · outline.json 개요 · manuscript.json 원고
   - illustration.json 예화 · application.json 적용 (만들었을 때만)
   - sources.json 출처 목록
5. 마지막에 Claude가 출처 점검을 돌려 결과를 보고합니다. 이때 모든 웹 출처를 다시 받아 확인합니다.
   - 몇 개를 확인했는지
   - 무엇이 '확인 필요'로 남았는지

3-1. 내 주석 자료 연결하기 (선택)
---------------------------------

가지고 계신 주석·설교집 PDF를 연결해 두면, 본문연구 단계에서 그 본문에 맞는 책을 골라 쪽 번호와 함께 인용합니다. 설교준비 도우미 페이지의 '내 자료 연결하기'에도 같은 안내가 있습니다.

1. 쓸 수 있는 자료
   - 글자가 들어 있는 PDF가 가장 잘 됩니다.
   - 스캔한 PDF(사진처럼 찍힌 쪽)도 글자 인식으로 읽을 수 있지만, 더 오래 걸리고 글자가 틀리게 읽힐 수 있습니다.
   - 한글(HWP) 파일은 아직 읽지 못합니다.
2. 정리하는 법
   - 주석을 폴더 하나에 모읍니다. 그 안에 시리즈별 하위 폴더가 있어도 괜찮습니다.
   - 파일 이름에 성경 책 이름, 저자, 시리즈를 넣습니다. 한 권이 책의 일부만 다루면 장 범위도 넣습니다.
   - 이름 예: 칼빈주석/칼빈주석 요한복음 1.pdf, 핸드릭슨 주석/핸드릭슨주석-요한복음(하).pdf, 카리스주석/카리스주석 신약 11 요한복음15-21장.pdf, NICNT/NICNT. 04 John - Leon Morris.pdf
3. 연결하는 법
   - Claude Code를 열고 이렇게 말씀하세요: "내 주석 폴더는 <폴더 경로>야. 연결해 줘"
   - Claude가 폴더를 등록하고 목록을 만든 뒤, 파일 수·PDF 수·성경 책을 알아본 책 수를 알려 드립니다. 스캔본이 얼마나 되는지는 책을 열어 보기 전에는 알 수 없습니다.
   - 폴더는 여러 개 연결할 수 있습니다(내 컴퓨터, 구글 드라이브, iCloud, OneDrive, 외장 드라이브). 빼려면 "<폴더 경로> 연결을 빼 줘"라고 하세요(폴더와 파일은 그대로 둡니다).
   - 클라우드 폴더도 괜찮습니다. 목록은 파일 이름만 보고 만들고, 실제로 쓰는 책만 그때 내려받아집니다.
4. 어떻게 쓰이나요
   - 본문연구 단계에서 그 본문에 맞는 주석을 1~3권 고릅니다. 개혁주의 저자의 책을 먼저 고릅니다.
   - 인용할 때는 저자, 책 이름, 쪽을 밝힙니다. 주석의 글 자체는 설교 페이지에 싣거나 게시하지 않습니다.
5. 저자 분류
   - 아직 분류되지 않은 저자의 책은 '비개혁주의 자료'로 표시하고 사실·원어·배경에만 씁니다.
   - 개혁주의 저자라면 "<저자>는 개혁주의 저자로 등록해 줘"라고 하세요. 근거를 확인한 뒤에 등록합니다.
6. 개인 정보: 연결한 폴더와 책에서 뽑은 글은 목사님 컴퓨터에만 남습니다(skills 폴더가 들어 있는 폴더의 .local/commentary/, 보통 ~/.claude/.local/commentary/).
7. 지금 되는 환경: macOS에서는 확인을 마쳤습니다. Windows 11에서도 2026-10-29~30에 설치·주석 도구 연결·서재 주석 읽기·스캔한 PDF 글자 인식·온라인 주석 읽기까지 확인을 마쳤습니다(아래 3-2). Windows에서는 먼저 '주석 도구 점검해 줘'라고 말씀해 주세요.

3-2. Windows에서 주석 자료 쓰기 (Windows 10/11)
-----------------------------------------------

  확인 상태(2026-10-30, 실제 Windows 11 PC): 설치, 1번 점검, 주석 도구 등록(3-3), 데스크톱 앱에서 주석 도구 연결, 온라인 주석 읽기를 확인했습니다. 클라우드 드라이브 폴더(파일 약 2,900개)를 서재로 연결해 5 본문연구에서 서재 주석 세 권을 골라 읽고 인용을 확인했고, 글자가 없는 진짜 스캔본 한 권(344쪽)을 Windows 글자 인식(windows-ocr)으로 읽어 한국어 글자를 얻었습니다(약 3분). 이 순서대로 하시면 됩니다.

1. 점검하기 — Claude Code를 열고 "주석 도구 점검해 줘"라고 말씀하세요. 다음을 쉬운 말로 알려 드립니다.
   - Node.js 버전(18 이상이어야 합니다. 없으면 https://nodejs.org 에서 LTS 버전을 설치하세요.)
   - PDF 글자 읽기 도구: 스킬에 들어 있는 pdf.js로 시험용 PDF를 실제로 읽어 봅니다. 따로 설치할 것이 없고 인터넷에 접속하지 않습니다.
   - 스캔한 PDF 글자 인식: Windows에 들어 있는 글자 인식에 한국어가 있는지 봅니다.
   - 연결한 주석 폴더가 있는지, 그 안의 파일·PDF 수.
   - Claude Code에 말씀하시면 아래 준비 없이 그대로 됩니다. PowerShell에서 직접 node ~/.claude/skills/sermon-commentary/scripts/commentary.mjs doctor를 실행하실 때만, 그 창에서 먼저 아래 한 줄을 실행하세요.
     chcp 65001
     (또는 [Console]::OutputEncoding = [System.Text.Encoding]::UTF8) 이 줄 없이 실행하면 한국어가 깨진 글자로 보입니다. 경로와 영어·숫자는 그래도 맞게 나옵니다. 창을 새로 열면 다시 실행합니다.
2. 한국어 글자 인식이 없다고 나오면 (스캔한 PDF만 해당 — 글자가 들어 있는 PDF는 그대로 됩니다) 직접 한 번 추가하세요. Claude가 대신 설치하지 않습니다.
   - 설정 → 시간 및 언어 → 언어 및 지역 → '언어 추가'에서 한국어를 추가합니다.
   - 또는 관리자 권한 Windows PowerShell(PowerShell 7 아님)에서:
     Get-WindowsCapability -Online | Where-Object { $_.Name -Like 'Language.OCR*ko-KR*' } | Add-WindowsCapability -Online
     (명령 형식 출처: Microsoft Learn, PowerToys Text Extractor 문서의 'Install an OCR language pack')
3. 폴더 연결 — 3-1과 같습니다. 경로 예:
   - 구글 드라이브(Google Drive for desktop): G:\내 드라이브\주석
   - OneDrive: C:\Users\<이름>\OneDrive\주석
   - 외장 드라이브: D:\주석 · 네트워크 폴더: \\서버\공유\주석
   - 탐색기 주소 표시줄의 경로를 복사해 붙여 넣으면 됩니다(따옴표가 있어도 괜찮습니다).
4. 클라우드 파일 — 구글 드라이브·OneDrive에서 컴퓨터에 내려받지 않은 파일은, 고른 책을 열 때 Windows가 그 파일만 내려받습니다. 내려받지 못했다고 나오면 탐색기에서 그 파일을 한 번 열거나 '항상 이 디바이스에 유지'(OneDrive)·'오프라인으로 사용 가능'(구글 드라이브)으로 바꾼 뒤 다시 하세요.
5. 스캔본 글자 인식 — Windows 글자 인식은 Windows PowerShell 5.1로 스킬 안의 pdfocr.ps1을 그 한 번만 실행합니다(-ExecutionPolicy Bypass는 그 실행에만 적용되고 컴퓨터 설정은 바꾸지 않습니다).

3-3. 설교준비 도우미에서 바로 출처 확인하기 (Claude 데스크톱 앱, 선택)
----------------------------------------------------------------------

주석 도구를 Claude 데스크톱 앱에 한 번 등록해 두면, 설교준비 도우미를 데스크톱 앱에서 열었을 때 9 출처 확인 단계에서 '출처 확인하기'를 눌러 바로 각주를 달 수 있습니다. 브라우저나 등록하지 않은 다른 컴퓨터에서는 지금처럼 Claude Code에 문장을 말씀하시면 됩니다. 페이지 주인(목사님 본인)만 쓸 수 있습니다.

1. 먼저 3-1처럼 주석 폴더를 연결해 둡니다.
2. Claude Code에 "주석 도구 등록 방법 알려 줘"라고 하시거나, 터미널에서 node ~/.claude/skills/sermon-commentary/scripts/commentary.mjs mcp-config를 실행하면 목사님 컴퓨터에 맞는 설정 파일 위치와 넣을 내용을 그대로 보여 드립니다.
   - macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
   - Windows: %APPDATA%\Claude\claude_desktop_config.json
   - Windows PowerShell에서 이 명령을 직접 실행하실 때는 그 창에서 먼저 chcp 65001(또는 [Console]::OutputEncoding = [System.Text.Encoding]::UTF8)을 한 번 실행하세요. 이 줄 없이 실행하면 한국어 안내가 깨진 글자로 보입니다. 설정 파일 위치와 넣을 내용(경로)은 그래도 맞게 나옵니다. Claude Code에 "주석 도구 등록 방법 알려 줘"라고 하시면 이 준비가 필요 없습니다.
   - 넣을 내용: "mcpServers" 안의 "sermon-sources" 항목 하나(command는 node 실행 파일, args는 스킬의 mcp/server.mjs 경로). 이미 다른 항목이 있으면 그 안에 이 항목만 더합니다.
3. Claude 데스크톱 앱을 완전히 종료했다가 다시 엽니다.
   - 출처 확인은 Bible Hub의 공개 온라인 주석(칼빈·매튜 헨리 등)도 목사님 컴퓨터에서 직접 읽습니다. 주석 도구(스킬)를 새 버전으로 바꾼 뒤에는 Claude 데스크톱 앱을 완전히 종료했다가 다시 열어야 새 기능이 보입니다(창만 닫으면 예전 도구가 그대로 돕니다). 예: 주석 도구 0.4.1부터는 네이버 키 파일 자리를 페이지에 알려 주고, 0.4.2부터는 Windows에서 그 자리를 C:\Users\<사용자이름>\.claude\.env.local처럼 전체 경로로 보여 줍니다. 0.4.2로 바꾼 뒤에도 데스크톱 앱을 완전히 종료했다가 다시 여세요.
4. 데스크톱 앱에서 설교준비 도우미를 엽니다. 주석 도구는 5 본문연구를 열 때 처음 쓰입니다. '본문연구 작성하기'를 누르면 '서재 주석 고르기'·'온라인 주석 읽기' 같은 진행 줄이 차례로 보입니다. 원고 초안이 생긴 뒤에는 10 출처 확인에서도 쓰입니다(원고가 없으면 10 출처 확인은 아직 열리지 않고 지금 단계로 돌아옵니다).

3-4. 웹 검색 키 넣기 (네이버, 선택)
-----------------------------------

출처 확인의 '웹에서 찾기'와 예화 단계의 '시사 예화 찾기'는 목사님 컴퓨터의 주석 도구가 네이버 검색을 씁니다. 페이지는 네이버에 직접 접속하지 않고, 키도 페이지로 보내지 않습니다. 예전 '네이버 개발자 센터'의 검색 API는 2026년 7월 31일부터 새 키를 주지 않으므로, 네이버 클라우드 플랫폼의 NAVER API HUB에서 받습니다(지금은 한시적 무료, 하루 25,000번).

1. 네이버 클라우드 플랫폼(ncloud.com)에 로그인하고 콘솔을 엽니다.
2. Services → Application Service → NAVER API HUB로 가서 이용 신청을 합니다.
3. Application 등록에서 검색 API(뉴스·웹문서·블로그·백과사전)를 고르고 등록합니다.
4. API 관리 → 인증 정보에서 Client ID와 Client Secret을 확인합니다.
5. skills 폴더가 들어 있는 폴더(보통 ~/.claude, Windows는 C:\Users\<사용자이름>\.claude)에 .env.local 파일을 둡니다. zip에 든 .env.example을 그 이름으로 복사하면 됩니다(이미 있으면 덮어쓰지 마세요).
       cp -n <zip을 푼 폴더>/.env.example ~/.claude/.env.local
   Windows PowerShell에서는(파일이 이미 있으면 그대로 둡니다):
       if (-not (Test-Path "$env:USERPROFILE\.claude\.env.local")) { Copy-Item "<zip을 푼 폴더>\.env.example" "$env:USERPROFILE\.claude\.env.local" }
   파일에는 아래 두 줄이 있습니다. 각 줄의 = 바로 뒤에 받은 Client ID와 Client Secret을 붙여 넣고 저장합니다.
       NAVER_CLIENT_ID=
       NAVER_CLIENT_SECRET=
6. Claude 데스크톱 앱을 완전히 종료했다가 다시 엽니다.

- 키는 이 컴퓨터의 .env.local에만 있습니다. 이 파일을 다른 사람에게 보내지 마세요. 배포용 zip과 페이지에는 들어가지 않습니다.
- 키가 없으면 페이지에 '검색 키가 아직 없어요. 내 자료 연결하기를 봐 주세요.'가 보이고, 나머지 출처 확인은 그대로 됩니다.
- 데스크톱 앱에서 주석 도구가 연결돼 있으면, 그 줄과 '내 자료 연결하기'에 이 컴퓨터의 실제 키 파일 자리(예: Mac은 '키 파일 자리: ~/.claude/.env.local', Windows는 '키 파일 자리: C:\Users\<사용자이름>\.claude\.env.local'처럼 전체 경로)가 함께 보입니다. 키 값은 보이지 않습니다.
- 검색 결과도 교리 기준을 거칩니다: 금지 목록의 단체·사이트와 개역한글 링크는 빼고, 목록에 없는 사이트는 '참고'(B 등급)로 표시합니다.

이 스킬들은 예장합동의 개혁주의 신앙고백을 기준으로 합니다(자세한 것은 sermon-sources/DOCTRINE.md).

- R 개혁주의 / 뜻: 칼뱅, 매튜 헨리, 매튜 풀, 벌코프 등; 합동·고신·합신 총회, 총신대, 기독신문 / 쓸 수 있는 곳: 교리·해석을 포함해 어디에나 / 화면 표시: 없음

- 글 속에 이단의 전형적인 표현(예: 보혜사를 특정 인물로, 어머니 하나님, 144,000에 들어가야 구원 등)이 나오면 점검이 멈추고 목사님의 검토를 기다립니다.

5. 출처 표시 읽는 법
--------------------

원고와 본문연구의 문장 끝에 작은 표시가 붙습니다.

- [^w3] / 뜻: 웹 출처 3번. sources.json에 주소·제목·사이트·저자·접속일·인용 구절이 있습니다.
- [^b2] / 뜻: 성경 구절 2번. 대한성서공회 개역개정 읽기 화면 링크가 있습니다.
- [^u1] / 뜻: 목사님이 주신 자료(묵상·붙여넣은 본문).
- [^?] / 뜻: 확인 필요. 출처를 찾지 못한 내용입니다. 설교 전에 직접 확인하시거나 빼 주세요.
- [^d?] / 뜻: 교리 확인 필요. 신앙고백 조항에 맞대어 보지 못한 교리 주장입니다. 목사님 검토 전에는 게시하지 않습니다.

sources.json의 상태:

- found / 뜻: 페이지를 다시 받아 보니 인용 구절이 글자 그대로 있었습니다. 출처로 인정합니다.
- not-found / 뜻: 페이지는 열렸지만 그 구절이 없었습니다. 출처로 쓰지 않습니다.
- unreachable / 뜻: 페이지를 글로 읽을 수 없었습니다(사이트가 막음·로그인 필요·자바스크립트 전용·PDF). 출처로 쓰지 않습니다.
- 등급 A / 뜻: 대한성서공회·교단·신학교·학술지·기독교 출판사·기독교 언론·공개 주석 사이트. 근거가 될 수 있습니다.
- 등급 B / 뜻: 개인 블로그·카페·위키·영상과 목록에 없는 사이트. '참고'로만 쓰이고, 혼자서는 근거가 되지 못합니다.

성경 문구에 대하여:
- 본문을 직접 붙여넣어 주시면 그 문구로 인용합니다.
- 붙여넣지 않으면 Claude가 기억으로 옮긴 개역개정 문구이므로 'AI 기억·확인 필요' 로 기록합니다. 링크를 눌러 대한성서공회 화면에서 확인해 주세요.
- 개역한글은 쓰지 않습니다.

6. 자주 묻는 것
---------------

- 'unreachable'이 많아요.
  - 일부 사이트는 프로그램의 접속을 막습니다(예: 봇 확인 화면).
  - Claude가 다른 등급 A 사이트를 찾아보거나, 그 내용을 '확인 필요'로 둡니다. 출처를 지어내지는 않습니다.
- 인용이 짧아요.
  - 다른 사람의 글은 한 번에 300자까지만, 출처와 함께 인용합니다.
- 믿을 만한 사이트를 더하고 싶어요.
  - ~/.claude/skills/sermon-sources/scripts/sites.json에 도메인을 더하고 등급(tier A/B)과 교리 등급(R/E/N), 이유를 적어 두세요.
  - 개혁주의(R)로 올릴 때는 그 기관이 실제로 개혁주의 신앙고백을 따르는지 확인해 주세요. X(금지)는 합동 총회 결의 페이지가 있을 때만 blocklist.json에 더합니다.
- 스킬을 새 판으로 바꾸려면?
  - 새로 받은 폴더들로 ~/.claude/skills/ 안의 같은 이름 폴더를 덮어쓰면 됩니다.
  - 이미 만든 sermons/ 폴더는 그대로 남습니다.
- 설교를 한 페이지로 보고 싶어요.
  - sermon-page를 함께 설치했다면 "설교 페이지 만들어 줘"라고 하세요.
  - Claude가 출처 점검 → 페이지 만들기 → 비공개 아티팩트 게시 순서로 진행하고 링크를 드립니다.
  - 페이지에는 일곱 탭(본문연구·설교 방향·개요·원고·예화·적용·출처 목록), 각주, 대한성서공회 읽기 링크, txt·md 내려받기, 문단 가벼운 고치기('원래 문장 보기'로 원문 비교)가 있습니다. 예화·적용을 만들지 않았으면 그 탭에는 안내 문장만 보입니다.
- 지난 설교를 한곳에서 보고 싶어요.
  - 0번에서 만든 설교준비 도우미 페이지 안에 '지난 설교' 목록이 있습니다. 그 페이지 주소는 sermons/hub.json에 적혀 있습니다.
  - 그 뒤로 설교를 게시하거나 다시 게시할 때마다 목록에 한 줄을 쓰거나 고칩니다(본문·준비한 날·확인된 출처·성경 구절·확인 필요 수).
  - 목록은 분류별로 묶이고, 분류가 없는 설교는 맨 끝 '미분류'에 있습니다.
  - 목록은 Claude에 로그인한 사람만 볼 수 있습니다. 로그인하지 않으면 "로그인해야 볼 수 있어요" 한 줄만 보입니다.
  - 공유는 페이지의 공유 버튼에서 직접 정합니다. 공유하면 링크를 가진 사람이 묵상·원고·출처를 모두 봅니다.
