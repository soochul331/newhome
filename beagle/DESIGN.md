# Beagle 스타일 디자인 가이드

## 1. 목적과 자료 범위

Beagle — Better proposals의 시각적 아이디어를 Church AI Lab 홈페이지에 적용하기 위한 디자인 가이드다. 기존 루트 DESIGN.md와 Apple·Tesla·Claude·Notion 가이드를 대체하지 않는다.

원본 페이지 접속이 불안정하여 Awwwards의 보관 이미지와 제작사 Spring/Summer의 프로젝트 설명을 참고했다. 원본 사이트의 현재 동작, CSS, 실제 폰트 파일은 확인하지 못했다. 아래 HEX, 크기, 여백, 애니메이션 수치는 원본에서 추출한 값이 아니라 구현을 위한 권장값이다. getdesign 패키지로 내려받은 공식 프리셋이 아닌 직접 작성한 참고 가이드다.

## 2. 참고 디자인에서 관찰한 특징

보관 이미지에는 민트색 배경 위로 흰색 문서가 여러 겹 배치되어 있다. 가운데 문서는 크게, 주변 문서는 작게 또는 화면 밖으로 일부 잘려 보인다. 그림자가 종이 사이의 깊이를 만든다. 큰 검은 산세리프 제목과 작은 세리프 설명이 대비를 이룬다. 로고와 로그인·가입 같은 탐색 요소는 상단에 간결하게 배치된다.

제작사는 제품 이미지 대신 종이를 비유로 사용해 인터랙티브 모션 그래픽으로 제안서 작성 과정을 설명했다고 소개한다. 또한 방문 시 다른 구성을 보여줄 수 있는 모듈형 사이트라고 설명한다. 현재 홈페이지에 적용할 때는 콘텐츠 순서를 고정하고, 종이와 단계별 설명이라는 아이디어를 중심으로 가져온다.

## 3. Church AI Lab 적용 방향

핵심 인상은 ‘어려운 AI를 차근차근 정리해 주는 학습 공간’이다. 종이는 제안서 대신 강의안, 질문 노트, 사역 계획, 교육 자료를 표현한다. 본문을 장식용 종이 안에 모두 밀어 넣지 않는다. 중요한 설명은 읽기 쉬운 일반 문서 흐름에 두고, 겹친 종이는 첫 화면과 단계 소개에 집중한다.

- 한 구획에는 한 가지 질문과 한 가지 다음 행동을 둔다.
- 장식보다 신학적 분별, 현장 실습, 실제 결과물을 먼저 전달한다.
- 과장된 성과나 가상의 고객·후기를 만들지 않는다.
- 기존 글, 문의 폼, 관리자 편집 기능을 유지한다.

## 4. 색상 권장값

| 토큰 | 값 | 용도 |
|---|---|---|
| canvas | #F7F7F2 | 일반 본문 배경 |
| mint | #92CDBD | 첫 화면과 학습 과정 배경 |
| mint-soft | #E4F1EB | 보조 구획 |
| paper | #FFFFFF | 문서 카드 |
| ink | #202622 | 제목·본문 |
| muted | #5C6962 | 설명·날짜 |
| line | #D4DED7 | 구분선·문서 내부 선 |
| action | #215B4A | 주요 버튼·링크 |
| action-hover | #174537 | 주요 버튼 호버 |
| accent | #D4A86B | 문서의 작은 표시·번호 |

민트는 넓은 배경에 사용한다. 버튼에는 짙은 녹색과 흰 글자를 사용한다. 밝은 민트 위의 흰 글자는 피한다. accent는 작은 장식에만 사용하며 중요한 정보를 색상만으로 구분하지 않는다. 실제 조합은 적용 단계에서 대비를 검사한다.

## 5. 글꼴과 타이포그래피 권장값

원본의 정확한 폰트명은 확인하지 않았다. 한국어 본문은 시스템 고딕을 기본으로 사용하고, 짧은 설명에만 명조를 선택적으로 적용한다.

| 역할 | 데스크톱 | 모바일 | 굵기·행간 |
|---|---|---|---|
| 첫 화면 제목 | 56–76px | 32–42px | 700 / 1.18–1.3 |
| 구획 제목 | 36–48px | 26–32px | 700 / 1.3 |
| 문서 제목 | 22–28px | 20–24px | 600 / 1.4 |
| 본문 | 18–20px | 17–18px | 400 / 1.75 |
| 작은 설명 | 14–16px | 14–16px | 400 / 1.6 |

- 고딕: system-ui, -apple-system, "Noto Sans KR", sans-serif.
- 명조: "Noto Serif KR", Georgia, serif. 필요한 경우에만 로드한다.
- 본문 폭은 약 60–72ch, 긴 한국어 제목에는 word-break: keep-all과 overflow-wrap: anywhere를 함께 고려한다.
- 제목에 과도한 음수 자간을 사용하지 않는다. 한국어 설명 전체를 좁은 행간의 영문 표제처럼 처리하지 않는다.

## 6. 레이아웃과 여백

- 전체 콘텐츠 최대 폭: 1200px.
- 일반 텍스트 최대 폭: 760px.
- 바깥 여백: 데스크톱 40–64px, 모바일 20–24px.
- 구획 위아래 여백: 데스크톱 96–144px, 모바일 56–80px.
- 첫 화면은 화면 높이에 가깝게 구성하되 콘텐츠가 길면 자연스럽게 늘어난다.
- 헤더는 64–80px 높이로 로고, 핵심 메뉴, 문의 버튼을 제공한다.
- 화면 아래 관리자 링크를 유지한다.

### 종이 구성

중앙에 주 문서 한 장을 놓고 양쪽에 보조 문서 2–3장을 배치한다. 장식 문서는 회전 ±4도, 위치 이동 16–48px 정도로 제한한다. 실제로 읽거나 클릭하는 문서는 회전시키지 않는다. 화면 밖으로 잘리는 요소는 장식에만 적용한다.

문서 모서리는 0–4px로 거의 직각에 가깝게 한다. 내부 여백은 24–40px, 그림자는 넓고 부드럽게 사용한다. 버튼의 둥근 형태와 문서의 직선 형태를 대비시킨다.

## 7. 홈페이지 구획 제안

1. **첫 화면 — 함께 배우는 AI**: 민트 배경, 큰 핵심 문장, 문의하기·학습 과정 보기 버튼. 종이에는 ‘질문 노트’, ‘교육 자료’, ‘나만의 AI’ 같은 짧은 표제를 둔다.
2. **분별 — 무엇을 맡기고 무엇을 지킬까요?**: 밝은 배경과 한 가지 질문. 기존 신학적 설명을 읽기 편하게 배치한다.
3. **네 단계 학습**: 분별과 책임 → 질문의 기초 → 실제 활용 → 나만의 도구. 네 장의 문서를 따라 읽도록 구성한다.
4. **함께 하는 일**: 신학적 분별, 현장 실습, 온라인 활동을 세 장의 문서 카드로 정리한다.
5. **소개와 근거**: 기존 경험·결과물·공인·기록을 차분한 텍스트 목록으로 제공한다.
6. **최근 글**: 실제 게시글 제목과 날짜를 유지하고 클릭 영역을 명확히 한다.
7. **문의**: 움직임 없는 단순한 폼과 짧은 안내. 입력·오류·완료 상태를 명확하게 제공한다.

## 8. 컴포넌트

### 주요 버튼

짙은 녹색 배경, 흰 글자, 높이 48–52px, 좌우 여백 24–32px, 둥근 모서리. 버튼 제목은 ‘문의하기’, ‘학습 과정 보기’처럼 행동을 설명한다. 보조 버튼은 투명 배경과 짙은 녹색 테두리를 사용한다.

### 문서 카드

상단에 작은 단계 번호, 중앙에 질문형 제목, 아래에 2–4줄 설명을 배치한다. 아래쪽 문서 줄무늬는 장식으로만 사용한다. 한 카드 안에 중복 링크를 여러 개 만들지 않는다.

### 탐색과 선택

메뉴는 일반 링크로 제공한다. 현재 위치, 키보드 포커스, 호버 상태를 각각 구분한다. 콘텐츠를 편집하는 관리자 화면에서는 장식 레이어가 텍스트 클릭을 막지 않게 한다.

## 9. 모션과 반응형

아래는 원본 동작의 재현값이 아닌 권장 구현 규칙이다.

- 등장: opacity와 translateY 16–24px, 400–600ms.
- 호버: 150–220ms, 카드 이동은 최대 4px.
- 패럴랙스: 장식 종이에만 약하게 적용한다. 본문·폼·편집 대상에는 적용하지 않는다.
- 스크롤을 강제로 한 장씩 넘기거나 가로채지 않는다.
- prefers-reduced-motion에서는 등장·패럴랙스를 제거한다.
- 모바일에서는 겹친 종이를 한 장의 문서나 세로 목록으로 바꾼다.
- 주요 정보와 문의 버튼은 애니메이션 없이도 처음부터 접근할 수 있어야 한다.

## 10. 구현 시작용 CSS 토큰

```css
:root {
  --beagle-canvas: #f7f7f2;
  --beagle-mint: #92cdbd;
  --beagle-paper: #fff;
  --beagle-ink: #202622;
  --beagle-muted: #5c6962;
  --beagle-action: #215b4a;
  --beagle-line: #d4ded7;
  --beagle-paper-shadow: 0 20px 56px rgb(32 38 34 / 16%);
  --beagle-content-width: 1200px;
  --beagle-text-width: 760px;
  --beagle-paper-radius: 3px;
}
```

테마를 실제 추가할 때는 기존 theme별 CSS 분리 방식에 맞춰 범위를 제한한다. 이 문서를 만드는 것만으로 홈페이지의 현재 테마나 배포 상태는 바뀌지 않는다.

## 11. 적용 확인 기준

- 기존 텍스트·링크·문의 폼·관리자 링크가 유지된다.
- 화면에 보이는 텍스트는 기존 시각 편집기에서 선택·수정할 수 있다.
- 겹친 종이는 장식이고 콘텐츠 순서와 키보드 탐색은 일반 문서 순서를 따른다.
- 375px 모바일에서 가로 스크롤이나 잘린 본문이 없다.
- 큰 제목과 한 가지 행동이 먼저 보이고, 실제 설명은 충분히 읽을 수 있다.
- 원본 로고·사진·일러스트를 무단 복사하지 않고 자체 콘텐츠로 구성한다.
