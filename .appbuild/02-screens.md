# 02-Screens — 관리자 페이지 화면 명세

상태: 1차 구현 반영본(2026-10-08). 관리자 화면은 Decap CMS 기본 UI(한국어)를 쓰므로 레이아웃은 CMS가 정하고, 여기서는 **어떤 화면이 있고 무엇을 할 수 있는지**만 정의한다.

## 1. 화면 목록과 흐름

```
/admin/ (로그인)
  └─ 깃허브로 로그인 ──▶ 컬렉션 목록 (좌측)
        ├─ 사이트 설정 ─┬─ 기본 정보   [S1]
        │               ├─ 메뉴         [S2]
        │               └─ 홈 화면      [S3]
        ├─ 페이지 (목록 → 새로 만들기/편집)   [S4]
        ├─ 글·소식 (목록 → 새로 만들기/편집)  [S5]
        ├─ 미디어 (상단 탭)                   [S6]
        └─ 작업 흐름 (상단 탭, editorial workflow) [S7]
```

## 2. 화면별 정의

| ID | 화면 | 상태(정상/빈/오류) | 주요 동작 | 대응 PRD |
|---|---|---|---|---|
| S0 | 로그인 | 로그인 전 / 거부(허용 계정 아님) | 깃허브 OAuth | F1 |
| S1 | 기본 정보 | 단일 파일, 항상 값 있음 | 이름·바이라인·메타·링크·저작권 수정 → 저장(초안) | F2 |
| S2 | 메뉴 | 항목 0개면 상단 메뉴 비어 보임(정상) | 항목 추가/삭제, 끌어 정렬, 표시·모바일 숨김 토글 | F3 |
| S3 | 홈 화면 | 섹션 0개면 홈이 비어 보임(경고만) | 섹션 종류 7가지 추가, 끌어 정렬, 켜기/끄기, 섹션별 필드 편집 | F4 |
| S4 | 페이지 | 빈 목록(처음) / 주소 형식 오류 시 저장 불가 | 새 페이지(제목·주소·메타·본문), 수정, 삭제 | F5 |
| S5 | 글·소식 | 목록 2개(초기) | 새 글(제목·날짜·외부 링크 또는 본문), 수정, 삭제, 날짜 정렬 | F6 |
| S6 | 미디어 | 빈 목록(처음) | 이미지 업로드·삭제, 본문에 삽입 | F7 |
| S7 | 작업 흐름 | 초안/검토 중/발행 준비 3열 | 카드 끌어 상태 변경, "발행" | F8 |
| — | 공개 사이트 | 빌드 실패 시 이전 버전 유지 | 발행 → 네티파이 빌드 → 반영 | F9·F10·F11 |

## 3. 고정(편집 불가) 요소
색·글꼴·버튼·카드 모양(`src/assets/style.css`, `src/_includes/`), 이름 표기 규칙(`scripts/lint-content.js`).
